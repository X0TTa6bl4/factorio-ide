# Совместимость с Factorio

## Постоянное требование

**Целевая версия — последняя стабильная версия полной Factorio.** Экспериментальные сборки и предварительные API не становятся целью автоматически. Это правило применяется к исследованию, реализации, тестам и выпуску приложения.

Версию определять по полю `stable.alpha` официального [API релизов](https://factorio.com/api/latest-releases); при работе с Space Age сверять также `stable.expansion`. Номер демоверсии не использовать: он может отставать. Страница [загрузки](https://factorio.com/download) различает stable и experimental.

На **09.11.2026**: `stable.alpha = stable.expansion = 2.1.24`; demo — `2.1.23`. Это текущая проверенная база документов, а не бессрочно закреплённая цель.

Повторная проверка **14.11.2026** при уточнении сетевого чтения и арифметических операндов: `stable.alpha = stable.expansion = 2.1.24`, версия справочного API совпадает. Обновлены соответствующие документы; проверка поведения запуском игры не выполнялась.

## Порядок обновления

1. Перед изменением игровой семантики и перед выпуском приложения проверить официальный stable-релиз.
2. Если номер изменился, прочитать изменения комбинаторов, сигналов и API между проверенной и новой версиями.
3. Обновить затронутые небольшие спецификации, каталог игровых данных и тестовые примеры.
4. Сверить спорные случаи с целевой игрой; API описывает настройки, но не все вычислительные нюансы.
5. Выпустить обновлённое приложение и указать проверенную версию. До этого не заявлять поддержку новой версии как завершённую.

Требование всегда ориентироваться на stable не означает, что уже открытая страница сама получила новую реализацию. Версия совместимости фиксируется в каждом выпуске приложения и сохранённой схеме; смена цели выполняется при обновлении проекта.

## Данные и дополнения

Различать версию движка, версию формата проекта и набор включённых игровых возможностей. Режимы, зависящие от Space Age/Quality и игровых прототипов, описывать отдельно от обычной арифметики. Отсутствие каталога предметов не подменять фиктивными размерами стаков и вместимостью ракеты.

Поддержка произвольных модов и нескольких исторических версий не входит в первый этап. При импорте схемы другой версии выдавать понятную диагностику или выполнять явно определённую миграцию; не менять её смысл молча.
