# Хранилище

Источник сигналов для заданного содержимого. Срез 19.11.2026 поддерживает только чтение этого списка. Слоты, запросы, температура и вся труба не считаются. Запуск Factorio 2.1.24 не выполнялся.

Источник описания: строки сундуков, логистических сундуков и резервуара в [Wiki сетей](https://wiki.factorio.com/Circuit_network), сверенные 19.11.2026 при stable 2.1.24.

## Конфигурация

Обязательны `enabled`, `mode` и `contents`. `mode` — строка `read`. Режимы `empty-slots`, `requests`, `enable`, `pipeline` и `temperature` дают `unsupported-case` и не заменяются пустым выходом. Другая строка — `invalid-mode`.

`contents` — массив `{ signal, constant }`. Сигнал обычный, количество — int32. Дубли одного канала складываются по int32 при публикации. Нулевая сумма не создаёт канал. Метасигнал запрещён.

Выходы `red_output` и `green_output` можно пропустить. Входы запрещены: режим read их не читает.

`enabled: false` публикует пустой вклад. Список при этом сохраняется в описании.

## Граница

Вклад есть уже на границе 0 и повторяется на следующих, пока описание прогона не пересобрано. Это то же правило, что у постоянного источника: содержимое не зависит от входа и не накапливается. Неподключённый выход в сеть не пишется. Второй источник в той же сети сохраняет свой вклад.

Профиль сигнала проверяется при регистрации. Сигнал другого профиля даёт `wrong-profile`.

Вместимость слотов, размер стака и логистическая сеть в этот список не входят. Число в `contents` — количество сигнала, а не число занятых ячеек.
