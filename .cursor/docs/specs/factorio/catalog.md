## Применение в симуляторе

### Тип сигнала и группа констант

Сверено 14.11.2026: stable и справочный API — **2.1.24**. В игровом `SignalIDType` восемь технических типов: `item`, `fluid`, `virtual`, `entity`, `recipe`, `space-location`, `asteroid-chunk`, `quality`. Разделы меню «Логистика», «Производство» и другие — группы, а не дополнительные типы каналов. [SignalIDType](https://lua-api.factorio.com/latest/concepts/SignalIDType.html), [ItemGroup](https://lua-api.factorio.com/latest/prototypes/ItemGroup.html).

В нашем API согласовано дерево классов с константами, например `Signal.Logistic.wooden_chest`. Этот пример соответствует `item/wooden-chest`, подгруппа `storage`, группа `logistics` в сохранённом каталоге. Такой доступ удобен для подсказок, но сам токен продолжает хранить полный игровой ключ. Число пользовательских разделов не задаёт число технических типов каналов.

В официальных данных и нашем снимке найдены группы для десяти пользовательских разделов: `logistics`, `production`, `intermediate-products`, `space`, `combat`, `fluids`, `signals`, `enemies`, `environment`, `other`. Группа `space` добавляется профилем Space Age. Сырой список содержит также `tiles` и `effects`; наличие группы данных само по себе не делает её разделом передаваемых сигналов. Wiki отдельно указывает размещение виртуальных/дополнительных сигналов в разделах Signals, Enemies, Environment, Unsorted. Это основание для предложенного дерева, а не отчёт о проверке полного меню в игре. [Группы base из Wube 2.1.24](https://github.com/wube/factorio-data/blob/2.1.24/base/prototypes/item-groups.lua), [подключение групп Space Age](https://github.com/wube/factorio-data/blob/2.1.24/space-age/data.lua), [сигналы Wiki](https://wiki.factorio.com/Circuit_network#Virtual_signals).

Не объединять предмет, сущность и рецепт с одинаковым именем. Генерация имён констант должна обнаруживать коллизии, сохранять различимые типы токенов и учитывать профиль base/Space Age. Предложение публичных имён дерева и явного выбора качества — в [API](../api.md).

У `SignalID.quality` значение по умолчанию — `normal`. В профиле Space Age уровни — `normal`, `uncommon`, `rare`, `epic`, `legendary` со значениями 0, 1, 2, 3, 5 соответственно. Их нельзя получать простым увеличением целого от 0 до 4. Различать качество как часть идентичности предметного сигнала и отдельный передаваемый сигнал технического типа `quality`. [SignalID](https://lua-api.factorio.com/latest/concepts/SignalID.html), [Quality](https://wiki.factorio.com/Quality).

### Использование данных

- Идентичность канала определена в [сетях и сигналах](networks.md); качество не размножает строки каталога заранее.
- Обычные виртуальные каналы отделять от [метасигналов](meta-signals.md).
- Параметры чертежей не исполнять как обычные предметы.
- Скрытые прототипы по умолчанию не показывать в пользовательском выборе.
- Правила автоматического скрытия рецептов с дублирующими иконками учитывать отдельно. У сырого Lua-каталога нет гарантии точного совпадения с игровым меню.
- Группы и порядок брать из данных, а не из русской алфавитной сортировки, когда это влияет на семантику выбора сигнала.

## Графические данные

Собраны описания 770 исходных PNG: пути и параметры слоёв. PNG отсутствуют в headless-дистрибутиве и в текущем результате. Формат позволяет дополнить их из полной установки игры; путь `__base__/…` нельзя непосредственно подставить в браузерный `img.src`.

Исходные Lua data stages выполнены локально без игрового сервера. Две сборки совпали побайтно; проверка итогового меню и C++-значений по умолчанию в игре не выполнялась. Исходники и версия зафиксированы в manifest.

Источник данных: [официальная сборка Wube](https://factorio.com/get-download/2.1.24/headless/linux64). Правила структуры: [SignalID](https://lua-api.factorio.com/latest/concepts/SignalID.html), [параметры прототипов](https://lua-api.factorio.com/latest/prototypes/PrototypeBase.html), [скрытие рецептов](https://lua-api.factorio.com/latest/prototypes/RecipePrototype.html#hide_from_signal_gui).

## Таблица публичных констант

Производная таблица 2.1.24 лежит в [data/signal-catalog/2.1.24](../../../../data/signal-catalog/2.1.24/manifest.json). Она собрана из снимка `data/factorio/2.1.24` и не заменяет сырые прототипы. Имя по-прежнему берётся из `prototype.name`: дефис становится подчёркиванием, регистр сохраняется. Контрольный путь `item/wooden-chest` — `Signal.Logistic.wooden_chest`.

В учёте 1218 строк base и 2249 строк Space Age. Экспортировано 569 и 876 путей. Эти числа не равны числу кнопок меню: `menuConfirmed` остаётся false, полный chooser 2.1.24 не сверялся. Скрытые и технические записи сохранены. Отсутствующий PNG не удаляет строку. Незаданное `hide_from_signal_gui` не записано как false; вывод для рецепта помечен уровнем documentation по [prototype docs 2.1.24](https://lua-api.factorio.com/2.1.24/prototypes/RecipePrototype.html#hide_from_signal_gui). Подпись со статусом unresolved не считается переводом `request_translation`.

Base и Space Age — отдельные профили. Space Age удаляет `item/satellite` и `recipe/satellite`, добавляет 1033 ID и меняет свойства 21 общего ID. Качества не размножают строки сигналов. В Space Age обычные уровни 0, 1, 2, 3, 5, уровень 4 между ними отсутствует. В base обычных сигналов качества нет. Применимость качества к каналу, если её нет в снимке, остаётся unconfirmed. Значение SignalID по умолчанию — `normal` по документации, не по runtime.

Для бочки предмет остаётся основным токеном: `item/barrel` — `Signal.Intermediate.barrel`, `item/water-barrel` — `Signal.Intermediate.water_barrel`. Рецепт наполнения `recipe/water-barrel` экспортируется как `Signal.Intermediate.water_barrel.fill`, рецепт опустошения `recipe/empty-water-barrel` — как `Signal.Intermediate.water_barrel.empty`. Листья `fill` и `empty` — имена нашего API по действиям Fill и Empty, не прототипные name. То же правило покрывает семь жидкостей base и девять Space Age, включая холодный и горячий фторкетон. Рецепт изготовления пустой бочки и скрытые recycling-рецепты этими листьями не становятся. Плоский путь вроде `Signal.Intermediate.empty_water_barrel` тем же рецептам не назначается.

`item/captive-biter-spawner` экспортируется как `Signal.Production.captive_biter_spawner`. `entity/captive-biter-spawner` остаётся в учёте без публичного пути: причина `project-item-only`. Это решение проекта, а не доказательство скрытия во вкладке врагов.

`item/biolab` экспортируется как `Signal.Production.biolab`. `entity/biolab` остаётся в учёте без публичного пути: причина `chooser-observation-item-only`. Основание — наблюдение пользователя 18.11.2026, что отдельного entity-сигнала в меню постоянного комбинатора нет. Версия, пакеты и настройки наблюдения не указаны. В снимке обе записи `hidden: false`; это не runtime-флаг скрытия и не подтверждение всего меню.

Четыре куска сопоставлены с предметом по blueprint `data/evidence/constant-combinator-asteroid-chunks-2026-11-18.blueprint.txt`. `blueprint.version` `562954249961473` декодируется как 2.1.24, младшие 16 бит равны 1. В секции кусков поле `type` отсутствует, у entity-фильтров той же выгрузки `type` равен `entity`. По [SignalID](https://lua-api.factorio.com/2.1.24/concepts/SignalID.html) отсутствующий `type` означает `item`. Публичные пути `Signal.Space.metallic_asteroid_chunk`, `Signal.Space.carbonic_asteroid_chunk`, `Signal.Space.oxide_asteroid_chunk` и `Signal.Space.promethium_asteroid_chunk` ведут к соответствующим `item/…-asteroid-chunk`. Парные `asteroid-chunk/…` остаются в учёте с причиной `chooser-blueprint-item`. Снимок не содержит `hide_from_signal_gui` и `item_signal_alias`; эти поля не выведены из blueprint и не записаны как false. Если снимок явно задаёт `hide_from_signal_gui: true` или непустой `item_signal_alias`, фрагмент по-прежнему не получает отдельный publicPath, и причина берётся из снимка. Пакеты и настройки видимости в blueprint нет. Это сопоставление четырёх сигналов, не подтверждение всего меню. Девять рецептов дробления, переработки и продвинутого дробления металлического, углеродного и оксидного кусков экспортируются отдельно и не сливаются с предметом куска. Рецептов прометиевого куска с такими именами в снимке нет. По решению 18.11.2026 ведущий цифровой блок до дефиса переносится в конец: `1x2-remnants` → `Signal.Environment.remnants_1x2`. Обзор — [review.md](../../../../data/signal-catalog/2.1.24/review.md), пары — [collisions.json](../../../../data/signal-catalog/2.1.24/collisions.json).
