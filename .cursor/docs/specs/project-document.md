# Формат локальной схемы

Согласованный контракт задачи 0017. Это описание файла и локальной записи, а не снимок runtime и не правила Factorio. Игровая семантика устройств остаётся в `factorio/`. Снимок опубликованной границы описан отдельно и в этот файл не входит.

## Версия

Корень — объект JSON:

| Поле | Версия 1 |
|---|---|
| `format` | строка `f-logic-project` |
| `version` | число `1` |
| `name` | имя схемы, 1–120 символов, без управляющих |
| `profile` | `base` или `space-age` |
| `gameVersion` | строка, совпадающая с `gameVersion` открытого профиля |
| `seed` | uint32 |
| `world` | `null` либо `{ origin, dayLength }` |
| `networks` | массив сетей |
| `groups` | массив групп постоянного комбинатора |
| `devices` | массив устройств |
| `scenarioState` | только `null` |

Другой `format` — `foreign-format`. Другая `version` — `unsupported-version`. Другой профиль — `unsupported-profile`. Несовпадение `gameVersion` — `unsupported-game`. Любое значение `scenarioState`, кроме `null`, — `unsupported-scenario-state`. Эти проверки выполняются до создания `Circuit` и до записи в хранилище.

Миграций версии 1 нет. Следующая версия добавляет функцию перехода со старого номера и только затем поднимает поддерживаемую версию. Неизвестная версия не применяется частично и не меняется молча.

`scenarioState` зарезервирован для будущего состояния сценария. Версия 1 поле хранит и принимает только `null`: runtime-снимок, тик, RNG, очереди и выходы сюда не записываются и из файла не восстанавливаются.

## Ссылки

Сеть: `{ id, name, color }`. ID имеет вид `nN`, имя — `red_*` или `green_*`, цвет совпадает с префиксом. ID не выводится из имени и не перенумеровывается при загрузке. После наибольшего ID следующий новый ID продолжает счёт.

Устройство: `{ id, name, kind, ports, config, source, receiver }`. ID имеет вид `dN`. Вид — `constant`, `arithmetic`, `decider`, `selector`, `event`, `lamp`, `storage`, `station` или `train`. `ports` содержит `red_input`, `green_input`, `red_output`, `green_output`: `null` или ID сети. Порты не дублируются внутри `config`. У поезда все четыре порта — `null`. В его `route` станция записана как `{ "kind": "device", "id": "dN" }`.

Группа: `{ id, name, filters }`, ID `gN`. В `config` ссылка — `{ kind: "group", id }`. Один ID даёт один объект группы всем секциям.

Получатель события — ID другого события или `null`. Цикл сетей и взаимные получатели записываются ID, поэтому документ конечен.

Токены внутри `config` и фильтров:

| Вид | Поля |
|---|---|
| `signal` | `type`, `name`, `quality` |
| `meta` | `name` |
| `quality` | `name` |
| `quality-selector` | `name` |
| `operation` | `owner`, `name` |

`quality` у сигнала обязательна. Каталог профиля проверяет сигнал, качество и селектор качества до сборки схемы. Настройки устройства лежат в `config`; настройки схемы — `seed` и `world`.

`source` — строка или `null` и допустим только у `event`. Загрузка сохраняет текст и не компилирует его: нет `eval`, `Function` и `import()`. Зарегистрированный блок — обычный `EventCombinator` с портами, `run` и начальным `state`. Выполнение текста остаётся явным действием страницы сценария.

## Атомарность

`readProject` либо возвращает документ и новый `Circuit`, либо бросает `ConfigError`. Открытая сессия заменяется только после успеха. Повреждённый JSON, повтор ID, отсутствующая сеть, устройство или группа не меняют уже открытую схему. Сообщение об отсутствующей ссылке содержит путь, например `devices.adder.ports.red_input`.

## Локальная запись

Каталог браузера хранит записи отдельно от открытой схемы. У записи собственный `recordId` вида `pN` и имя. Импорт файла меняет только память.

Сохранение с именем, которое уже есть у другой записи, без `replace: true` даёт `name-collision` и ничего не пишет. `replace: true` заменяет запись с этим именем. Новое имя создаёт новую запись. Обновление той же `recordId` не считается коллизией.

Отказ хранилища — `storage-unavailable`. Переполнение — `storage-quota`. Неудачная запись не затирает предыдущее значение ключа; если каталог не обновился после записи схемы, новая запись откатывается. Открытая схема в памяти при этом остаётся.

## Чертёж Factorio

Этот файл не является blueprint. Строка чертежа и JSON с корнем `blueprint` не проходят `readProject`: первая даёт `invalid-json`, второй — `foreign-format`, если у него нет `format: "f-logic-project"`. Открытая схема при ошибке остаётся. Граница будущего обмена и причина, по которой импорт чертежа не запланирован, записаны в [дополнительных средствах](future-tools.md).
