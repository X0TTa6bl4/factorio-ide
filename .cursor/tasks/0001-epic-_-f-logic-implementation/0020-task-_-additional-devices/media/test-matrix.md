# Матрица дополнительных устройств

До реализации шаг 0100 выбирает конкретные устройства, режимы, профили и ожидаемые игровые результаты. Каждая строка параметризуется выбранным устройством; недостающие правила не заменять предположениями. Это задания, не результаты прогонов. ID связать с тестами, [общей стратегией](../../media/testing-strategy.md) и отдельно с игровыми свидетельствами.

| ID | Вход, шаг и действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| AD-01 | Для каждого выбранного устройства и режима задать минимальную корректную конфигурацию | Конфигурация принимается; опубликованный результат на указанной контрактом границе равен согласованному эталону | контрактный, интеграционный |
| AD-02 | Те же входы на red, green и обоих входах | Суммы и выбор цвета соответствуют правилам сети и конкретного устройства; разные сети не сливаются | контрактный, интеграционный |
| AD-03 | Выход red, green, оба или null | Вклад появляется только в подключённых выбранных сетях; другие источники сохраняются | интеграционный |
| AD-04 | Изменить вход на границе t | Ожидаемый вклад виден на границе, определённой контрактом устройства; читатель не наблюдает строящийся next | интеграционный |
| AD-05 | Удалить входной сигнал или отключить источник | Исчезновение/удержание вклада соответствует контракту; устаревший вклад не накапливается | интеграционный |
| AD-06 | Пустой набор, нулевое и предельное int32 значение | Для каждого выбранного режима — явно табулированный результат по правилам сетей и согласованной игровой семантике | контрактный, property |
| AD-07 | Ошибочные настройки, неподдержанный режим или отсутствующий профиль | Явная диагностика; нельзя молча заменить режим пустым выходом | контрактный |
| AD-08 | Перестановки устройств и цикл с обратной связью | Опубликованная последовательность неизменна; нет рекурсивного внеочередного расчёта | property, интеграционный |
| AD-09 | Экспорт и импорт схемы с выбранным устройством и подключениями | Версия, конфигурация и стабильные ID сохраняют смысл; повторный прогон выдаёт ту же последовательность | интеграционный |
| AD-10 | Сопоставить устройство с событийным прототипом при одинаковых входах | Таблицы выходов по границам совпадают в согласованном общем подмножестве; различия явно объяснены | интеграционный |
| AD-11 | Сверить каждый выбранный игровой режим с актуальной stable и доступными эталонами | Источник, версия, дата и статус проверки записаны отдельно от результата автоматического теста; непроверенные случаи отмечены | проверка соответствия игре |
| AD-12 | Перебор граничных и некорректных конфигураций выбранных режимов | Правила покрыты тестами; достижимые ветви и исключения отражены в карте покрытия | контрактный, property |
