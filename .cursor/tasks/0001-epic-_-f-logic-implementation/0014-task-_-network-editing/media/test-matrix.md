# Матрица проверок: Редактирование сетей

Это план будущих проверок, а не результаты прогона. Общая [стратегия](../../media/testing-strategy.md).

| ID | Вход или действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| 01 | Обычный: создать красную сеть и подключить два порта | оба ссылаются на один объект и ID. | Браузер / интеграция |
| 02 | Граница: переименовать сеть с несколькими связями | ID и все связи сохранены, новое имя отображается. | Браузер / интеграция |
| 03 | Ошибка: зелёная сеть в красном порту, строка или сеть другой схемы | ошибка конкретного поля, запуск запрещён. | Браузер / интеграция |
| 04 | Ошибка: удалить сеть с подключениями | согласованное действие не оставляет висячих ссылок; отмена не меняет схему. | Браузер / интеграция |
| 05 | Граница: правка во время запуска | пауза и сброс до применения, старые результаты не выдаются за текущие. | Браузер / интеграция |
| 06 | Пустой порт | `null`; неизвестный идентификатор не создаёт сеть неявно. | Браузер / интеграция |
