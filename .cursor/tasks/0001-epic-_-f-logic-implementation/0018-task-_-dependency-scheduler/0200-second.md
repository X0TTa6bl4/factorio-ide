# Эквивалентность эталону

Родительская задача: [Пересчёт по зависимостям](./0000-dependency-scheduler.md).

## Skills этого шага

- реализация: `repo-orientation-ru`
- проверка: `ci-failure-fix` при сбое.

## Контекст

См. родительскую задачу и [матрицу проверок](./media/test-matrix.md).

## Результат

Эквивалентность эталону: самостоятельный проверяемый результат в рамках родительской задачи.

## Границы

### Входит

- Индекс читателей, первая очередь всех устройств, сохранение собственных вкладов, планирование по фактическому изменению сети и пробуждения устройств с состоянием.

### Не входит

- Работа других этапов и публикация.

## План

- [ ] Выполнить относящуюся к результату часть родительской задачи и проверки.

## Критерии приёмки

- [ ] Результат шага соответствует границам и применимым случаям матрицы.
- [ ] Фактические результаты проверок записаны в родительской задаче.

## Проверка

- Написать и запустить соответствующие целевые контейнерные тесты; полный набор выполнить перед завершением родителя.
