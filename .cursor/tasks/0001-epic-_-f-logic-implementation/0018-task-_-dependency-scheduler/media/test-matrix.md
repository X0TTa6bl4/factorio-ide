# Матрица проверок: dependency-scheduler

Будущие проверки, не отчёт о прогоне. Неподтверждённые игровые случаи отделять от проектной модели.

| ID | Вход / действие | Ожидаемый результат | Тип |
|---|---|---|---|
| SCH-1 | Стабильный writer после первого расчёта | Пропущенный пересчёт сохраняет его прежний вклад | поведенческий |
| SCH-2 | Обе входные сети изменились на одной границе | Один расчёт устройства за следующий шаг | поведенческий |
| SCH-3 | Два вклада изменились с взаимной компенсацией | Сумма сети не изменилась; читатель не пробуждается из-за неё | поведенческий |
| SCH-4 | Выход только в красный цвет | Вклад только в красной сети; зелёная не меняется | поведенческий |
| SCH-5 | Самоссылка A+1→A | Границы 0,1,2,3; без рекурсивного вызова | трасса |
| SCH-6 | null-операнд и false/false | null не даёт вклад; обычный сигнал на пустом входе читается как 0 | поведенческий |
| SCH-7 | Источник перестаёт давать вклад | Старый вклад заменён пустым, канал исчезает при отсутствии других источников | поведенческий |
| SCH-8 | Пробуждение time/random/event без изменения входов | Устройство пробуждается по своему согласованному расписанию | интеграционный |
| SCH-9 | Reset и первый расчёт, включая два константных операнда | Начальная очередь и состояние эквивалентны полному проходу | поведенческий |
| SCH-10 | Фиксированные и генеративные схемы с seed | Full scan = optimized на каждой границе: сети, выходы, runtime, RNG, сообщения, wakes | свойство |
| SCH-11 | Мутации задержки, хранения вклада и сравнения сетей | Соответствующие мутации обнаружены; уцелевшие разобраны | mutation |
