# Матрица проверки полной таблицы

Это будущие проверки. Правила и источники — в [корне](../0000-signal-constant-catalog.md) и [карте](sources.md). Число сырых записей, число экспортов и число реально видимых сигналов — отдельные метрики.

| ID | Данные / действие | Ожидание | Вид проверки |
|---|---|---|---|
| CAT-01 | Все восемь входных типов обоих профилей | Каждый (profile,type,name) учтён ровно один раз; нет чужих ID | set equality |
| CAT-02 | wooden-chest; signal-A; signal-each | wooden_chest; signal_A; Signal.Meta.signal_each, исходный name сохранён | unit |
| CAT-03 | Имена a-b и a_b; одинаковое имя разных типов | Явный конфликт, ни затирания, ни автосуффикса | negative |
| CAT-04 | `1x2-remnants`; внутренние цифры; недопустимый JS-символ; keyword/служебное свойство | `remnants_1x2` с исходным ID; внутренние цифры сохраняются; коллизия после переноса не затирает запись; остальные недопустимые имена остаются в отчёте | unit/contract |
| CAT-05 | Одинаковая запись с разной en/ru подписью | publicPath не меняется от языка или перевода | property |
| CAT-06 | item/entity/recipe wooden-chest | Разные игровые ключи; exported/excluded с причиной, объединения нет | integration |
| CAT-07 | Удалённый satellite и изменённые общие ID Space Age | Профили самостоятельны; availability/метаданные корректны, не union | regression |

| CAT-09 | Each/Everything/Anything, любой quality, blueprint-parameter | Разные роли; только разрешённые контексты, не обычный сетевой канал | contract |
| CAT-10 | Пустая/несуществующая subgroup либо group | Явная ошибка или учтённое отсутствие; не произвольный Unsorted | negative |
| CAT-11 | Одинаковые order, пустой order, другая locale машины | Детерминированный итог; group/subgroup/prototype order сохранены | property |

| CAT-14 | Quality normal/legendary и wildcard; уровни с пропусками | Качество канала отделено от quality-сигнала; нет умножения каждой строки на N | contract |
| CAT-15 | Recipe hide_from_signal_gui не задан, иконка совпадает с item | Не считать отсутствующее поле false; применить подтверждённый default/проверку | game/runtime fixture |
| CAT-16 | Hidden prototype и типичный доступный сигнал | Учёт обоих, статус выбора подтверждён/помечен; hidden не удалён молча | integration |
| CAT-17 | PNG отсутствует или icon многослойный | Описание/порядок слоёв и missing сохранены; ID не пропал | unit |
| CAT-18 | Документация latest иной версии, изменившийся архив/loader hash | Диагностика смешения происхождения; нет silent upgrade | negative |
| CAT-19 | Перестановка файлов/ключей и две чистые генерации | Производные JSON/индекс побайтно совпадают | reproducibility |
| CAT-20 | Каждый экспортируемый publicPath и обратное разрешение | Однозначная исходная тройка/роль, никакой смены type/name | round-trip |
| CAT-21 | Стабильный ID в base/Space Age, но разные свойства | Путь стабилен при неизменной доступности; метаданные профильные | regression |
| CAT-22 | Следующая версия с добавлением/удалением/коллизией | Объяснённый version-diff; старое имя не переназначено другому ID | regression |
| CAT-23 | Пустой/повреждённый вход, дубли ID, конфликт схемы JSON | Сборка завершается ошибкой; старые опубликованные результаты не испорчены | negative |
| CAT-24 | Приёмка 2.1.24 по существующему снимку | Баланс 1218/2249 учётных строк, а не столько же видимых констант; для новой версии новый baseline | coverage |

| CAT-25 | Пустая бочка, water-barrel и оба рецепта | `barrel` → item/barrel; `water_barrel` → item/water-barrel; `.fill` → recipe/water-barrel; `.empty` → recipe/empty-water-barrel; разные токены, без крафта/мутации; вложенный round-trip | contract |
| CAT-26 | Все бочки обоих профилей, включая холодный/горячий фторкетон | 7 комплектов base / 9 Space Age; соответствие жидкости, EN/RU действий и игровых ID; recycling не принят за действие; нет молчаливых плоских дублей | integration |
| CAT-27 | item/entity captive-biter-spawner | Только предмет имеет Signal.Production.captive_biter_spawner; сущность сохранена с проектной причиной отсутствия пути; отсутствие во вкладке врагов не записано как runtime-доказательство | contract |
| CAT-28 | Четыре пары item/asteroid-chunk; biolab отдельно | Проверены hide_from_signal_gui/item_signal_alias/chooser нужной версии; при alias/скрытии нет выдуманного второго сигнала; при двух независимых сигналах различение согласовано; исходные ID учтены | runtime/client + contract |
| CAT-29 | Десять вкладок Space Age, исправленные пользователем через согласованный обмен чертежом; base отложен 18.11.2026 | Публичный ordinary-набор точно совпадает с 693 ключами принятой ручной сверки; происхождение и версия записаны. Это не автоматический полный обход GUI и не вывод о видимости из одного успешного импорта; base не блокирует текущую приёмку | user review / set comparison |
| CAT-30 | Подтверждённый набор в обычных сигнальных полях других комбинаторов | Общие ID и имена; ограничения конкретных режимов отдельны; meta/wildcard/параметры разрешаются по контексту и не теряются из-за отсутствия в постоянном | contract |

Для каждого случая сохранить результат и происхождение ожидания (project rule / documentation / runtime / client). Мутации удаления строки, слияния типов, потери профиля, переименования от locale и затирания коллизии должны обнаруживаться тестами. Тесты алгоритма не доказывают полноту игрового меню без независимой сверки.
