# Ограничения данных и история проблем задачи 0002

Итог 18.11.2026: задача завершена в согласованном объёме Space Age после ручной пользовательской сверки десяти групп. Блокирующих вопросов для приёмки таблицы нет. `menuConfirmed` остаётся false: исчерпывающий автоматический обход всех режимов GUI не заявляется. `collisionsResolved` равен true. Неизвестные переводы и отдельные условия качества явно обозначены в данных; они не требуют повторной приёмки уже согласованного рабочего набора.

Пользователь сообщил: модов кроме Space Age нет; скрины меню сняты на последней версии. По API релизов в этот день последняя стабильная — 2.1.24, экспериментальная — 2.1.25. Целевая версия проекта — последняя стабильная, поэтому кадры относятся к 2.1.24. Экспериментальная 2.1.25 к ним не приписывается.

## Что уже не является проблемой

Имена вроде `Signal.Logistic.wooden_chest` и `Signal.Environment.remnants_1x2` собраны. Тесты в Docker: `./dev/f-logic test`, 40/40.

## Актуальный итог после самостоятельной проверки

Обновление после возврата пользовательского чертежа 18.11.2026: [сверка десяти групп](../../../../../data/evidence/constant-combinator-review-2026-11-18/README.md) применена к каталогу. Environment содержит 79 ключей вместо 264, удалённые 185 сохранены в техническом учёте. В Unsorted добавлены пять ключей; ordinary-набор теперь 693 сигнала и точно совпадает с возвращённым экспортом. Прежняя необходимость выяснить, какие именно записи Environment убрать, закрыта пользовательской правкой. Повторный запрос того же набора не нужен. Отдельные утверждения о полном обходе GUI/других качествах этим файлом не подтверждаются.

18.11.2026 официальная headless Factorio 2.1.24 (build 87808) реально запущена в Docker для base и Space Age. Хеш архива совпал с исходным снимком. [Данные и воспроизведение](../../../../../data/evidence/runtime-2.1.24-2026-11-18/README.md).

Закрыто:

- **Пункт 5:** runtime вернул hide_from_signal_gui=true и предметный item_signal_alias для каждого из четырёх asteroid-chunk. Отсутствие этих полей в старом data-stage JSON больше не является недостатком свидетельства. Сами старые JSON не изменены.
- **Production из пункта 3:** при ручном чтении кадра 54 клетки, все соответствуют 54 экспортам. Прежние 53 — ошибка приблизительного подсчёта. [Построчное сопоставление](production-review.md).
- **Пункт 10:** на том же кадре одна биолаборатория, строка 6, столбец 10. Это согласуется с наблюдением пользователя; повторно выбирать правило item/entity не нужно.
- **Пункт 9:** две оранжевые кнопки не мешают идентифицировать содержимое вкладки жидкостей. Это особенность свидетельства, не самостоятельный блокер.
- **Пункт 6:** неподходящие чужие списки исключены из эталонов. Их наличие в интернете не требует решения пользователя и не блокирует наш генератор.
- **Пункт 8:** PNG не обязательны для текстовой таблицы по границам задачи. Их отсутствие ограничивает автоматическое распознавание скриншотов, но само по себе не блокирует сборку.

Дополнительно исправлен реальный пропуск `recipe/rocket-part`: скрытый item с той же иконкой больше не скрывает рецепт; отсутствующие subgroup/order рецепта наследуются от главного продукта с указанием происхождения. Все унаследованные значения и visibility обычных рецептов обоих профилей проверены против runtime. Появились `Signal.Intermediate.rocket_part` для base и `Signal.Space.rocket_part` для Space Age.

Известные ограничения для дальнейшей проверки при необходимости:

1. Полный состав меню Space Age не сопоставлен целиком. Отдельные совпавшие вкладки не подтверждают весь набор. Сверка чистой base отложена пользователем 18.11.2026 и не является блокером текущей приёмки.
2. Environment: конкретный набор уже получен в исправленном пользовательском чертеже, 79 ключей, и применён. Проблема 185 лишних публичных записей закрыта. Правило selectable_in_game по-прежнему не используется как универсальная замена меню; дальнейшие режимы видимости проверяются отдельно при необходимости.
3. Сложные переводы через клиент и применимость качеств. Headless-запуск не вызывал request_translation и не проверял графические фильтры качества.

Графического клиента Factorio в стандартных локальных расположениях не найдено. Headless не предоставляет снимок меню, поэтому отдельный автоматический обход GUI не подтверждён. Рабочий ordinary-набор принят по согласованной процедуре обмена исправленным пользовательским чертежом; задача закрыта, дополнительные решения пользователя не ожидаются.

## Исходный список до этой проверки

1. Меню не подтверждено ни для одного профиля целиком. Критерии CAT-29 и CAT-30, шаги 0200 и 0300 открыты. Состав ordinary-набора нельзя объявлять равным chooser.

2. Чистой базы нет. Десять скринов — только Space Age: [constant-combinator-chooser-2026-11-18](constant-combinator-chooser-2026-11-18). Вкладки базы без Space Age не сняты.

3. Скрины Space Age не сопоставлены со строками таблицы значок к значку. Автоматический подсчёт клеток совпал с экспортом у Logistic (73), Space (50) и Fluids (22). Production: 53 на кадре и 54 в таблице. На серых значках вкладки Signals и на плотной вкладке Intermediate подсчёт сбивается, поэтому оттуда строки не вычёркивались.

4. Environment на кадре заканчивается пустыми клетками, около 70 значков. Таблица экспортирует 264 сущности `hidden: false`. Среди них 126 `remnants`, 32 corpse и 10 stump. `hidden: false` в снимке не доказывает кнопку в меню. Эти пути из каталога пока не сняты: кадр не называет каждый лишний `type/name`.

5. `hide_from_signal_gui` и `item_signal_alias` у четырёх `asteroid-chunk` в снимке отсутствуют. Из blueprint и из `hidden: false` они не выводятся. В интерфейсе этих полей нет. Критерий про сверку остаточных коллизий по chooser/alias из-за этого открыт, хотя пути бочек и улья уже собраны.

6. Чужие полные списки из сети нельзя принять за меню 2.1.24. [Выгрузка 2.0.77](https://gist.github.com/Number-3434/09a78a4142a4753c2176d3ca313749a8) обходит все прототипы, включая скрытые и редактор. [Комбинатор на 13 194 сигнала](https://factorioprints.com/view/-P4hp_8rE0UHpv7GOJRb) помечен как 2.1.23 и включает скрытые предметы и скрытые уровни качества. У этих списков нет картинок, поэтому скрины не вычёркивают из них отдельные строки.

7. Сложная локализация и C++-значения по умолчанию не сверены с клиентом. `request_translation` не вызывался. Подпись со статусом `unresolved` не является переводом. Применимость качества к каналу, если её нет в снимке, остаётся `unconfirmed`. На скринах выбран фильтр обычного качества; это не проверка остальных качеств.

8. PNG иконок в снимке нет, поэтому значок на скрине нельзя программно наложить на `prototypeId`. Описание слоёв иконки этот разрыв не закрывает.

9. На кадре жидкостей оранжевая заливка есть и у кнопки компонентов. Открытый список при этом — жидкости. Для этой вкладки кадр читается однозначно, но заливка двух кнопок остаётся пометкой к свидетельству.

10. Наблюдение по `entity/biolab` сделано раньше и без записанной тогда версии. Новые скрины Space Age к этой паре отдельно не разбирались.
