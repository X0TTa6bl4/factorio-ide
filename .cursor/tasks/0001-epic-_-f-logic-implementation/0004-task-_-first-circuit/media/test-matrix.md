# Матрица проверок: first-circuit

Будущие проверки, не отчёт о прогоне. Неподтверждённые игровые случаи отделять от проектной модели.

| ID | Вход / действие | Ожидаемый результат | Тип |
|---|---|---|---|
| FIRST-1 | Constant A=3; Arithmetic A+2→B | t0 A=3; t1 B=5; reset возвращает t0 | сквозной |
| FIRST-2 | Вычислитель перестаёт выдавать B через допустимый тестовый источник | После публикации B отсутствует и читается 0 при отсутствии других источников | поведенческий |
| FIRST-3 | Отключённый вход, A+5→B | B=5 на следующей границе | поведенческий |
| FIRST-4 | null-операнд или отсутствие return | Нет выходного вклада; старый вклад исчезает | поведенческий |
| FIRST-5 | Отключённый выход | В сеть ничего не передаётся | поведенческий |
| FIRST-6 | Смешанные поля, неверный тип, out-of-range или цвет | Диагностика без частичного запуска | негативный |
| FIRST-7 | Статическая страница: step и reset | Отображаются тик и сеть; DOM не нужен ядру | браузерный |
