# Матрица Worker первого среза

План по [контракту](../../../../docs/specs/event-combinator.md), не отчёт о прогоне. Проверять настоящий браузерный Worker в Docker и общий checkpoint.

| ID | Действие | Ожидание | Уровень |
|---|---|---|---|
| EW-01 | Отдельная страница компилирует наследника EventCombinator | Конфигурация схемы остаётся на основной странице, main работает в Worker | browser |
| EW-02 | Успешный await createSimulation/step/reset | Согласованный t0/ровно t+1/t0; интерфейс показывает только опубликованное | browser |
| EW-03 | Второй step пока первый ожидает prepare | Диагностика занятости; не начинается второй шаг | integration |
| EW-04 | main с бесконечным циклом | Timeout прерывает Worker, UI отвечает; тик и checkpoint прежние | browser |
| EW-05 | Exception/ошибка синтаксиса/невалидный result/state | Показаны блок, тик и доступное место; частичный commit отсутствует | browser |
| EW-06 | Reset до готовности prepare и поздний ответ | Новый runId, t0; поздний ответ не принят | browser |
| EW-07 | Чужая revision/stepId/phase/tick; повторный ответ | Отклонение протокола; нет двойной публикации | contract |
| EW-08 | Один блок успешен, второй завис/упал | Нет частичного общего тика; выходы, RNG, messages, wakes прежние | integration |
| EW-09 | Abort и восстановление Worker | Restore из checkpoint без init; повтор шага воспроизводим | integration |
| EW-10 | Изменение кода во время step | Прогон остановлен, старая revision не применяется; новый запуск после проверки | browser |
| EW-11 | Promise/thenable из main | Явный отказ; асинхронное продолжение не публикуется | browser |
| EW-12 | Статический сервер под /factorio-ide/ | Все модули/Worker загружаются; нет серверного API | browser |
| EW-13 | Ошибка самой worker-связи | Пауза и диагностика, контроль не остаётся навечно в busy | browser |
| EW-14 | Управляемая пауза между шагами | Нет самопроизвольного изменения виртуального тика | browser |
