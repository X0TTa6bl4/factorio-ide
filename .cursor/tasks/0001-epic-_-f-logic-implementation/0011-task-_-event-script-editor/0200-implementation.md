## План

Страница `pages/event/index.html` использует каркас библиотеки: редактор, настройки события, диагностику и диалог снимка. `createEventScriptSession` собирает модуль и не исполняет текст сценария на главном потоке. Worker получает blob-URL. Оболочка — обычный `EventCombinator` с портами `red_1` и `green_1`. Сессия держит один шаг, отменяет его по reset, правке и `stop`, после timeout или остановки продолжает с опубликованного checkpoint без `init`.
