## Контекст

По уточнению пользователя 16.11.2026 событийный блок входит в первый срез. [Контракт](../../../docs/specs/event-combinator.md) определяет ранее открытые формы; это проектная модель, отсутствующая в Factorio. Страница `pages/event/index.html` редактирует сценарий и исполняет его в останавливаемом Worker.

## Цель

Пользователь редактирует полноценный JS сценария отдельно, исполняет его по шагам и может остановить зависший код.

## Границы

### Входит

- Простая отдельная страница и останавливаемый Worker; сложная IDE-библиотека не является зависимостью первого среза.
- Протокол init/prepare/commit/abort/restore с runId, revision, stepId, phase, tick; чужой/повторный/устаревший ответ отклоняется.
- Асинхронный публичный исполнитель: await createSimulation/step/reset; только один шаг в работе, согласованная граница после завершения.
- Timeout, ошибка и reset отменяют подготовку; восстановление из опубликованного checkpoint без повторного init при restore.
- Работа под GitHub Pages: относительные пути Worker/модулей и отсутствие прикладного сервера.

### Не входит

- Перенос всего движка в Worker, асинхронный main, полная изоляция произвольного JS от сети.
- Основной конфигурационный редактор и облачное сохранение.

## Критерии приёмки

- [x] Бесконечный цикл прекращается лимитом исполнителя, UI отвечает и частичный тик не опубликован.

- [x] Повторный step во время активного отклоняется, успешный await меняет тик ровно на 1.
