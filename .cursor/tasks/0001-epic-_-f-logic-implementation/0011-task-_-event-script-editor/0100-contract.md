## План

- [x] Подготовить результат и проверки.

Протокол `runId` / `revision` / `stepId` / `phase` / `tick`, лимит хоста и отдельный счётчик ревизии сценария записаны в [событийном контракте](../../../docs/specs/event-combinator.md). `revision` протокола остаётся номером контракта движка. Лимит по умолчанию 1000 мс, целое от 1, номер виртуального тика не меняет. Комментарии, обычные строки и шаблонные литералы не считаются объявлением или импортом; код внутри `${...}` остаётся кодом.
