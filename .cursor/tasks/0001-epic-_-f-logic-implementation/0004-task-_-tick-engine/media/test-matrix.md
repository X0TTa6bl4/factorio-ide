# Матрица проверок: tick-engine

Будущие проверки, не отчёт о прогоне. Неподтверждённые игровые случаи отделять от проектной модели.

| ID | Вход / действие | Ожидаемый результат | Тип |
|---|---|---|---|
| TICK-1 | Constant A=3; reset | t0: A=3, вычисляемые выходы пусты; reset повторяет t0 | поведенческий |
| TICK-2 | A=3 → вычислитель +2 → второй +1 | t0: A=3, B/C отсутствуют; t1 B=5, C=1; t2 B=5, C=6 при обычном чтении отсутствующего B как 0 | трасса |
| TICK-3 | A+1→A без другого источника | t0=0, t1=1, t2=2, t3=3; без рекурсии | трасса |
| TICK-4 | Многоузловой цикл и перестановка массива устройств | Все опубликованные границы идентичны при перестановке | свойство |
| TICK-5 | Источник прекращает вклад по допустимому сценарию | На следующей публикации старый вклад исчезает, next не накапливает сумму | поведенческий |
| TICK-6 | Вычислитель выбрасывает ошибку до публикации | Тик, сети, выходы и runtime остаются прежними; повтор воспроизводим | негативный |
