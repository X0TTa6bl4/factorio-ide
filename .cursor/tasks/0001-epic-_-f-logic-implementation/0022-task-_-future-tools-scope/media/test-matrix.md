# Матрица проверок: Решение об инструментах будущих этапов

Это план будущих проверок, а не результаты прогона. Общая [стратегия](../../media/testing-strategy.md).

| ID | Вход или действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| 01 | Обычный: сценарий создания сложной схемы | решение об интерфейсе обосновано наблюдаемой потребностью. | Документ |
| 02 | Граница: blueprint содержит устройства или данные вне модели | матрица явно определяет отказ, ограничение либо отложенное исследование; потери не скрываются. | Документ |
| 03 | Ошибка: некорректный или несовместимый blueprint | выбранный контракт диагностики исключает молчаливую порчу схемы. | Документ |
| 04 | Анализ: предложенная проверка сложной сети | указаны вход, ожидаемый вывод и ограничения; семантика не объявлена проверенной без сверки. | Документ |
