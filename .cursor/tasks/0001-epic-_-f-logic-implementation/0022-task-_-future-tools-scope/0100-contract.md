# Исследование сценариев и ограничений

Родительская задача: [0000-future-tools-scope.md](./0000-future-tools-scope.md).

## Skills этого шага

- реализация: `repo-orientation-ru`; при уточнении спецификаций — `task-sdd-handoff-ru`.
- проверка: дополнительные обязательные skills не требуются.

## Контекст

Исследовать реальные сценарии визуальных проводов, импорта/экспорта blueprint и анализа; определить матрицу поддерживаемых случаев, совместимость, риски и приоритет; после решения сформировать конкретные последующие задачи только для принятого объёма.

## Результат

Исследование сценариев и ограничений: самостоятельный проверяемый результат в границах родительской задачи.

## Границы

### Входит

- Зафиксировать и согласовать входы, ограничения и наблюдаемый контракт первой части работы; применить соответствующие случаи матрицы.

### Не входит

- Автоматическая реализация всех инструментов, изменение игрового ядра и публикация.

## План

- [ ] Уточнить контракт и реализовать либо документировать первую часть согласно типу задачи.

## Критерии приёмки

- [ ] Контракт и результат первой части позволяют независимо проверить соответствующие случаи матрицы.

## Проверка

- Проверить документ, матрицу и ссылки; выполнение приложения не требуется.
