# Контракт грамматики и средства редактора

Родительская задача: [0000-configuration-editor.md](./0000-configuration-editor.md).

## Skills этого шага

- реализация: `repo-orientation-ru`; при уточнении спецификаций — `task-sdd-handoff-ru`.
- проверка: дополнительные обязательные skills не требуются.

## Контекст

Общая модель и проверки движка; вложенные discriminated-формы, совместимость всех условий и выходов, дерево Signal и Operation enums с профилем; отдельная конфигурационная грамматика без произвольного eval. Свободный JS только на странице событий.

## Результат

Контракт грамматики и средства редактора: самостоятельный проверяемый результат в границах родительской задачи.

## Границы

### Входит

- Зафиксировать и согласовать входы, ограничения и наблюдаемый контракт первой части работы; применить соответствующие случаи матрицы.

### Не входит

- Неограниченное выполнение кода в основном редакторе, обязательный TypeScript, сборщик или фреймворк.

## План

- [ ] Уточнить контракт и реализовать либо документировать первую часть согласно типу задачи.

## Критерии приёмки

- [ ] Контракт и результат первой части позволяют независимо проверить соответствующие случаи матрицы.
