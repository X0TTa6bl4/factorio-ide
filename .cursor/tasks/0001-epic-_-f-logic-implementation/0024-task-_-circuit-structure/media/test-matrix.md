# Матрица проверок: разбор структуры

Контракт — [дополнительные средства](../../../../docs/specs/future-tools.md). Это план тестов задачи 0024, не отчёт о прогоне.

| ID | Вход | Ожидание |
|---|---|---|
| S1 | Постоянный пишет `red_1`, арифметический только читает `red_1` | Писатель и читатель на местах; `cyclic: false`, `self` пуст, `witness: null` |
| S2 | Одно устройство читает и пишет одну сеть; его id `d3` | `self` содержит это устройство; `witness` равен `["d3","d3"]` |
| S3 | `d1` пишет сеть, которую читает `d2`; `d2` пишет другую сеть того же цвета, которую читает `d1` | `witness` равен `["d1","d2","d1"]` |
| S4 | Лампа, поезд, хранилище с выходом, станция с выходом, событие с текстом `source` | Лампа и поезд отсутствуют в писателях; хранилище и станция есть по выходам; слова внутри `source` не добавляют портов |
| S5 | Строка не-JSON, JSON `{blueprint:...}`, строка `0eNq` | Коды `invalid-json` или `foreign-format`, отчёт не возвращён |
| S6 | Документ с сетью без единого порта | Сеть есть в `networks` с пустыми списками |
| S7 | Две сети и два устройства с id не по порядку объявления | Порядок сетей, читателей и писателей — по числовому id, как в контракте |
