## Контекст

Контракт отчёта записан в [дополнительных средствах](../../../docs/specs/future-tools.md). Функция строится поверх `readProject`.

`circuitStructure` для корректного документа возвращает сети и `feedback` в заданном порядке.

## Границы

### Входит

- Модуль `src/circuit-structure.js`.
- Тесты прямой петли, цикла из двух устройств, шины без цикла, лампы, поезда, хранилища, станции и события с текстом `source`.

### Не входит

- Страница, шаг симуляции, правка формата файла.
