# Матрица проверок: snapshot-history

Будущие проверки, не отчёт о прогоне. Неподтверждённые игровые случаи отделять от проектной модели.

| ID | Вход / действие | Ожидаемый результат | Тип |
|---|---|---|---|
| HIST-1 | Снимок, несколько шагов, восстановление и повтор | Совпадают границы, выходы, runtime и состояние RNG | воспроизведение |
| HIST-2 | Сообщения в очереди и будущие пробуждения при снимке | После восстановления доставка и пробуждения совпадают; повторного исполнения нет | воспроизведение |
| HIST-3 | Изменить состояние после снимка | Снимок не меняется | изоляция |
| HIST-4 | Шаг назад и новое продолжение | Новая ветка не использует старое будущее согласно согласованному контракту | ветвление |
| HIST-5 | Несериализуемое состояние, неверный снимок, исчерпанный предел | Диагностика и поведение по согласованному контракту; восстановление атомарно | негативный |
| HIST-6 | Очередь пересчёта и reset | Очередь сохранена либо однозначно восстановлена без исполнения сценариев; reset по контракту | интеграционный |
