## Требования Worker

Пользователь пишет полноценный JavaScript на отдельной странице; зависший код должен останавливаться, а ошибка или timeout не должны частично публиковать шаг. Для restart/reset и защиты от устаревших сообщений нужны versioned run IDs. Worker сам по себе допускает сетевой доступ, включая fetch, и не является sandbox; ограничения внешних API требуют отдельного контракта. Основной редактор конфигурации относится к 0015, сохранение — к 0016.
