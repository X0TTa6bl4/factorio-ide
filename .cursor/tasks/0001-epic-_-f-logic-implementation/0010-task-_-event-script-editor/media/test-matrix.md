# Матрица страницы JavaScript и Worker

Будущие проверки, не результаты прогонов. Контракт шага 0100 должен определить формат протокола и ошибок до реализации; связывать ID с тестами и [общей стратегией](../../media/testing-strategy.md).

| ID | Вход, шаг и действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| EW-01 | На отдельной странице пользователь задаёт наследника EventCombinator с main и запускает шаг | Код выполняется в Worker; результат t→t+1 соответствует runtime, основной редактор остаётся конфигурационным | браузерный, интеграционный |
| EW-02 | main на 0→1 устанавливает A=1; следующий блок читает A | A виден на 1, выход следующего блока на 2; ответ Worker не публикует next раньше границы | браузерный, интеграционный |
| EW-03 | Синтаксическая ошибка и исключение внутри main | Понятная диагностика с доступными блоком, тиком и местом ошибки; шаг не опубликован | браузерный, контрактный |
| EW-04 | Бесконечный цикл в main | Timeout останавливает Worker, интерфейс отвечает; тик, сети, state, выходы, RNG, сообщения и wake остаются на последней границе | браузерный, интеграционный |
| EW-05 | Один блок ответил успешно, другой завис или выбросил исключение | Общий шаг не публикуется частично; восстановление и состояние паузы следуют контракту | интеграционный |
| EW-06 | Ответ Worker приходит после timeout | Ответ отвергнут, никакие данные старого шага не опубликованы | контрактный, браузерный |
| EW-07 | Reset или restart во время незавершённого шага; старый Worker отвечает позже | Новый versioned run ID отличается; старый ответ не изменяет новый тик, состояние, очереди и выходы | браузерный, интеграционный |
| EW-08 | Pause во время ожидания ответа и последующее продолжение | Поведение отмены/ожидания по контракту; без несанкционированного продвижения тика и двойной публикации | браузерный |
| EW-09 | Два ответа на один запрос, ответ с неверным ID или повреждённым payload | Лишний/неверный ответ отклонён с диагностикой по контракту; текущий прогон не повреждён | контрактный, интеграционный |
| EW-10 | Promise, таймер или иной async результат | Допустимость и момент завершения определены контрактом; недопустимое действие диагностируется, нет частичной публикации | контрактный, браузерный |
| EW-11 | Worker аварийно завершается; затем restart и восстановление сериализуемого снимка | Ошибка видима, прежняя граница сохранена; повтор шага даёт тот же результат при условиях воспроизводимости | браузерный, интеграционный |
| EW-12 | Проверка внешних API, включая fetch | Worker сам по себе не считается сетевым sandbox; проверяются только явно согласованные ограничения, без необоснованных гарантий | контрактный, браузерный |
