## Контекст

Страница `pages/networks/index.html` редактирует подмножество документа сетей через общий Circuit. [Проект](../../../docs/specs/project.md), [API](../../../docs/specs/api.md), [редактор](../../../docs/specs/editor.md), [план развития](../../../docs/specs/roadmap.md).

## Цель

Пользователь создаёт сети и подключения, сохраняя идентичность и корректность схемы.

## Границы

### Входит

- Автоматическое создание сетей редактором/движком, ссылки на объекты текущей схемы, фильтр цветов, стабильные ID, переименование и удаление с проверкой зависимостей; при изменении схема ставится на паузу и runtime сбрасывается.

### Не входит

- Графический холст проводов, сохранение файла и свободное выполнение JS.
- Установка инструментов или реализация в ходе планирования.

## Требования и ограничения

- HTML, CSS, обычный JavaScript и нативные ES-модули; без обязательных TypeScript, сборщика и фреймворка. Устанавливаемые инструменты разработки и проверки запускаются через Docker задачи 0001, не через host npm.
- Движок независим от DOM и таймера, описание схемы отделено от состояния; игровую совместимость заявлять только после сверки с последней stable.

## Уточнённый контракт сетей

Основной источник — [редактор](../../../docs/specs/editor.md): _new первым, существующие по MRU и префиксу, явное создание своего имени, повторное использование удалённого числового имени с новым ID. Переименование — по символам, undo восстанавливает идентичность.

Индекс обновляется по revision, полный разбор и Circuit-валидация обязательны перед запуском. Удаление неиспользуемой сети допустимо только в корректной завершённой транзакции, не при временной синтаксической ошибке. Не путать этот кеш с current/next и очередью пересчёта тиков.

- [x] green_new атомарно создаёт сеть и заменяется настоящим именем.
- [x] Ввод green_buffer фильтрует совпадения; собственное имя создаётся подтверждением.
- [x] MRU меняется от использования, не от просмотра; цвета и текущая схема фильтруются.
- [x] Неиспользуемая сеть удаляется, пустая по сигналам используемая — сохраняется.
- [x] Устаревшая revision не меняет подсказки/реестр; перед запуском проверяется текущий текст.
