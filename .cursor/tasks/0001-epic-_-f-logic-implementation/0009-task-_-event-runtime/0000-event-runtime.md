## Согласованная семантика

- Наследник `EventCombinator` переопределяет `main`, получает четыре порта и `tick` только для чтения. Чтение входов использует неизменяемый снимок `current[t]`.
- `setOutput` удерживает собственный вклад до изменения, `clearOutput` очищает его, `pulse` ограничивает длительность; каждое действие выбирает red, green или оба. Точные формы аргументов и столкновения остаются открытыми.
- По умолчанию `main` вызывается каждый тик; режим по изменению входов или назначенному пробуждению задаётся явно. Предлагаемый инвариант планировщика: не более одного вызова за шаг при совпадении причин запуска; подтвердить в контрактном шаге. Публикация всех результатов — на общей границе t→t+1.
- Сообщения между блоками доставляются через следующую границу; порядок вызовов не должен менять результат. Данные для будущей истории 0017 включают сериализуемые состояние, RNG, очереди, расписания и выходы.
- Инициализацию всех блоков завершить до формирования общей границы 0, не читая частично подготовленные сети. Точную форму и обработку ошибок согласовать до реализации.
