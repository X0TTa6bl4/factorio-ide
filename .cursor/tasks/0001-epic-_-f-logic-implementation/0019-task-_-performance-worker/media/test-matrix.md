# Матрица проверок: performance-worker

Будущие проверки, не отчёт о прогоне. Неподтверждённые игровые случаи отделять от проектной модели.

| ID | Вход / действие | Ожидаемый результат | Тип |
|---|---|---|---|
| PERF-1 | Цепи, циклы, разреженные/плотные сети нескольких размеров | Зафиксированы реальные результаты времени тика, памяти, отзывчивости, среда и повторения | измерение |
| PERF-2 | Одни входы и seed для full scan и optimized | Сопоставимые реальные измерения и семантически одинаковые границы | сравнение |
| PERF-3 | Сопоставить результаты с согласованными порогами | Записано обоснованное решение; значения порогов не выдумывать | анализ |
| PERF-4 | Если Worker нужен: step/reset, ошибки и порядок команд | Границы эквивалентны основному потоку; Worker не использует DOM; отзывчивость измерена | браузерный |
