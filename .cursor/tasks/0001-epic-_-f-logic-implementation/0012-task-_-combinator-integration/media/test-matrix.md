# Матрица проверок

A/B/C — разные обычные каналы; R/G — красный/зелёный вход. t+1 — следующая граница при подключённом выходе. Числовые ожидания ниже — модель спецификации, не результаты запуска игры. [Правила](../../../../docs/specs/factorio/ticks.md), [метасигналы](../../../../docs/specs/factorio/meta-signals.md), [совместимость](../../../../docs/specs/compatibility.md).

| Правило | Сценарий | Ожидание |
|---|---|---|
| Цепочка | constant A=3 → arithmetic A+2→B → decider B>0→C=1 | initial A=3; t1 B=5; t2 C=1 при подключённых сетях |
| Цикл | constant A=1 и arithmetic A+1→A в собственной сети | проектная модель [тиков](../../../../docs/specs/factorio/ticks.md): t0 A=1, затем 3, 5, 7; предыдущий снимок, без неподвижной точки |
| Разветвление | один вход разных цветов, выходы устройств на общую сеть | суммы по ключам и задержки каждого устройства; нулевой итог отсутствует |
| События | event изменяет выход, читаемый игровым устройством | доставка на следующей границе по контракту event; нет синхронного обхода тика |
| Сброс | random и time после нескольких тиков; reset и повтор с тем же seed/миром | повторяемые состояния и выходы согласно контракту reset |
| Ошибка | некорректный блок события или конфигурация устройства | диагностика и восстановление по контракту, отсутствие повреждения соседних устройств |

Добавить selector вместе с остальными четырьмя игровыми устройствами и event; разные качества, отрицательные/отменённые каналы, отключение и повторное подключение, изменение входов по тикам. Проверить историю и восстановление RNG, время разных миров, изменение групп и сброс, не дублируя общие тесты сетей и tick-engine. Не устанавливать неподтверждённую фазу time или random без fixture.

Непроверенные игровые ветви допускаются к поддержке только после fixture и обновления спецификации; до этого требуется явная диагностика неподдерживаемого случая. Проверять атомарность ошибки после принятия общего контракта ошибок.
