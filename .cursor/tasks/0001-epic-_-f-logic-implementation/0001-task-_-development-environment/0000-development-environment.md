# Контейнерное окружение разработки и тестов

## Контекст

Будущая реализация опирается на [спецификацию](../../../docs/specs/project.md), [API](../../../docs/specs/api.md) и [план развития](../../../docs/specs/roadmap.md). Согласованную модель отличать от неподтверждённых игровых случаев.

## Цель

Повторяемые команды разработки и проверок работают в Docker без установки Node, npm или браузеров на хост.

## Границы

### Входит

- Закрепить версии образа Node, test runner, инструмента покрытия и headless browser; lockfile dev-зависимостей. Подготовить статический dev-server, быстрый unit-прогон и полный прогон с покрытием и headless browser (например Playwright только как dev-зависимость в Docker). Документировать установку Docker, если он отсутствует; сейчас ничего не устанавливать. Учитывать существующие data/tools без обязательной пересборки каталога.

### Не входит

- Публикация, коммит, произвольные дополнительные устройства и работа соседних задач. Для конечного пользователя прикладной сервер не нужен.

## Политика тестирования

- Писать тесты: да, поведенческие и пограничные по [матрице](./media/test-matrix.md).
- Запускать тесты: да, целевые и полный набор в контейнерном окружении 0001.
- Для достижимых statements, строк, функций и ветвей ядра цель — 100%; исключения обосновать, сложные ветви не исключать ради процента. Поддерживать карту «правило → кейс», не подменять качество процентом. См. [общую стратегию](../media/testing-strategy.md).

## Критерии приёмки

- [x] Чистый контейнер воспроизводимо запускает быстрые и полные проверки; сайт доступен как статические HTML/CSS/native ES modules по ссылке без прикладного сервера.
- [x] Инструменты запускаются через Docker; версии и lockfile закреплены. Node и headless browser не нужны конечному пользователю.
- [x] Процесс контейнера работает обычным пользователем; исходники на host bind mount не становятся root-owned и остаются редактируемыми на хосте. Dev-server привязан к localhost.
- [x] Smoke-тест загружает ES-модуль; временная намеренно неверная assertion даёт ненулевой exit code. Coverage включает неисполненные исходники; артефакты сохраняются после удаления контейнера.
- [x] Выполнены применимые проверки из матрицы; неподтверждённые игровые случаи отмечены отдельно.
