# Контейнер и закреплённые инструменты

- проверка: `ci-failure-fix` при сбое.

## Контекст

См. родительскую задачу и [матрицу проверок](./media/test-matrix.md).

## Результат

Контейнер и закреплённые инструменты: самостоятельный проверяемый результат в рамках родительской задачи.

## Границы

### Входит

- Закрепить версии образа Node, test runner, инструмента покрытия и headless browser; lockfile dev-зависимостей. Подготовить статический dev-server, быстрый unit-прогон и полный прогон с покрытием и headless browser (например Playwright только как dev-зависимость в Docker). Документировать установку Docker, если он отсутствует; сейчас ничего не устанавливать. Учитывать существующие data/tools без обязательной пересборки каталога.

### Не входит

- Работа других этапов и публикация.
