# Матрица проверок: development-environment

Случаи проверки. Отчёт прогона 2026-11-17 — в [родительской задаче](../0000-development-environment.md). Игровой семантики в этой задаче нет.

| ID | Вход / действие | Ожидаемый результат | Тип |
|---|---|---|---|
| ENV-1 | Чистая сборка контейнера | Закреплённые версии и lockfile воспроизводимы; установки только внутри Docker | интеграционный |
| ENV-2 | Запустить быстрый и полный набор | Unit отдельно; полный включает coverage и headless browser | интеграционный |
| ENV-3 | Создать и изменить файл через bind mount | Обычный пользователь; файл не root-owned и редактируется на хосте | интеграционный |
| ENV-4 | Запустить dev-server | Порт на хосте опубликован на 127.0.0.1; сервер внутри контейнера доступен через проброс; статическая страница открывается | интеграционный |
| ENV-5 | Загрузить ES-модуль в smoke-тесте | Модуль успешно исполняется | smoke |
| ENV-6 | Временно добавить заведомо ложную assertion | Runner возвращает ненулевой exit code; assertion затем удалена | негативный |
| ENV-7 | Включить неисполненный исходник; удалить контейнер после прогона | Исходник отражён в coverage; отчёты остались на хосте | интеграционный |
| ENV-8 | Открыть готовую страницу пользователем | Не нужны Node, Playwright или прикладной сервер | браузерный |
