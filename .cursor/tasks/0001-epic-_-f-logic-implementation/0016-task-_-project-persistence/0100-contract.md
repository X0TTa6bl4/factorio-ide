# Контракт формата и кодирование

Родительская задача: [0000-project-persistence.md](./0000-project-persistence.md).

## Skills этого шага

- реализация: `repo-orientation-ru`; при уточнении спецификаций — `task-sdd-handoff-ru`.
- проверка: дополнительные обязательные skills не требуются.

## Контекст

Версионированный формат определения, стабильные ID связей вместо циклических объектов, токены сигналов и качества, профили, настройки и исходники событий; атомарная загрузка и диагностика; точка расширения для состояния сценария. Импорт не запускает пользовательский код.

## Результат

Контракт формата и кодирование: самостоятельный проверяемый результат в границах родительской задачи.

## Границы

### Входит

- Зафиксировать и согласовать входы, ограничения и наблюдаемый контракт первой части работы; применить соответствующие случаи матрицы.

### Не входит

- Снимок runtime и история/откат задачи 0017, облако, автоматическое исполнение сценария при загрузке.

## План

- [ ] Уточнить контракт и реализовать либо документировать первую часть согласно типу задачи.

## Критерии приёмки

- [ ] Контракт и результат первой части позволяют независимо проверить соответствующие случаи матрицы.

## Проверка

- Написать и запустить относящиеся к шагу тесты и сценарии матрицы через Docker-контур 0001; зафиксировать фактические результаты.
