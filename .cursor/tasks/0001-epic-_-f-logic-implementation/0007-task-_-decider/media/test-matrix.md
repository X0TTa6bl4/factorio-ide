# Матрица проверок

A/B/C — разные обычные каналы; R/G — красный/зелёный вход. t+1 — следующая граница при подключённом выходе. Числовые ожидания ниже — модель спецификации, не результаты запуска игры. [Правила](../../../../docs/specs/factorio/decider.md), [метасигналы](../../../../docs/specs/factorio/meta-signals.md), [совместимость](../../../../docs/specs/compatibility.md).

| Правило | Вход и настройка | Ожидание на t+1 |
|---|---|---|
| Сравнения | A=2: A >, <, =, >=, <=, != 2 | false, false, true, true, true, false; повторить значения 1 и 3 |
| Приоритет | A=1,B=0,C=0; A>0 OR B>0 AND C>0 | true, а не false |
| Пусто | A отсутствует; A=0 / A>0; null-операнд | true / false; null условие false |
| Ветки | A=5,B=9; A>0, true: B copy; false: C=5 | B=9; при A=0 C=5 |
| Копирование | R:B=4; G:B=5; копия B с R/G/RG/нет | B=4/5/9/пусто |
| Each | A=150,B=50,C=200; Each>100 | true Each copy A=150,C=200; false B=50; true Each constant 1: A=1,C=1; true D constant 1: D=2 |
| Each выражение | те же входы; Each>100 AND Each<200 | A=150 |
| Each пусто | пустой вход; Each=0 | нет кандидатов |
| Everything/Anything | пустой вход, сравнение >0 | Everything true; Anything false |
| Everything | A=1,B=150,C=50; A=1, выход Everything copy | все три канала |
| Ошибки | Each-выход без Each; Everything с Each; метасигнал справа; неполные маски, смешанные формы, неверный тип операции | диагностика |

Параметризовать обе ветви, все шесть сравнений, AND/OR, маски R/G/RG/нет, знаки и границы, отсутствующие/обнулившиеся каналы и разные качества. Проверить исключение обычного правого сигнала из кандидатов Anything/Everything, но не Each. Проверить допустимость выхода Anything при наличии и отсутствии Each; точный выбор подтвердить игровым fixture. Разные маски условий и копирования, смешанные метасигналы, OR и false, копирование конкретного выхода при Each, повторные выходы и фиксированные метасигналы требуют игровых эталонов. Мутации сравнения и приоритета должны обнаруживаться тестами.

Непроверенные игровые ветви допускаются к поддержке только после fixture и обновления спецификации; до этого требуется явная диагностика неподдерживаемого случая. Проверять атомарность ошибки после принятия общего контракта ошибок.

Проверить для каждого выхода true и false: конкретный фиксированный и копируемый, допустимые Each, Everything, Anything; `null` и `[]` дают пустую ветку. При A=1, B отсутствует: A>0 и B copy дают пусто, а B constant 5 дают B=5. При A=3,B=-2 и Each>0 выход Each copy даёт A=3. Условия null OR (A=1) при A=1 истинны; null AND (A=1) ложны. Игровой fixture обязателен для недоказанных комбинаций.
