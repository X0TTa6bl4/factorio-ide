# Матрица проверок: Браузерный отладчик

Это план будущих проверок, а не результаты прогона. Общая [стратегия](../../media/testing-strategy.md).

| ID | Вход или действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| 01 | Обычный: запуск на несколько тиков и пауза | номер и состояние соответствуют числу вызовов `step()`. | Браузер / интеграция |
| 02 | Граница: смена скорости и ручной шаг после паузы | следующая последовательность совпадает с ручным эталоном. | Браузер / интеграция |
| 03 | Граница: reset после работы | начальный тик и выходы согласно контракту движка; повтор воспроизводим. | Браузер / интеграция |
| 04 | Ошибка: неверная конфигурация или ошибка расчёта | понятная диагностика; ошибочная схема не продолжает выполнение. | Браузер / интеграция |
| 05 | Инспекция: два источника в одной сети | агрегат и собственный выход выбранного источника не смешаны; исчезнувший сигнал отмечен как изменение. | Браузер / интеграция |
