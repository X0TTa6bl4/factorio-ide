# Проверка статического размещения

Родительская задача: [0000-demo-release-readiness.md](./0000-demo-release-readiness.md).

## Skills этого шага

- реализация: `repo-orientation-ru`; при уточнении спецификаций — `task-sdd-handoff-ru`.
- проверка: дополнительные обязательные skills не требуются.

## Контекст

Несколько демонстрационных схем четырёх устройств и событийного сценария, инструкции HTTP-запуска, проверка относительных путей модулей и ресурсов, отображение проверенной версии совместимости.

## Результат

Проверка статического размещения: самостоятельный проверяемый результат в границах родительской задачи.

## Границы

### Входит

- Завершить интеграцию результата первого шага и проверить все критерии и случаи матрицы родителя.

### Не входит

- Фактическая публикация, настройка удалённого репозитория и Git init, прикладной сервер и обязательная сборка.

## План

- [ ] Довести результат до сценариев приёмки и проверить интеграцию.

## Критерии приёмки

- [ ] Результат соответствует критериям родителя; ошибки и граничные случаи обработаны.

## Проверка

- Написать и запустить относящиеся к шагу тесты и сценарии матрицы через Docker-контур 0001; зафиксировать фактические результаты.
