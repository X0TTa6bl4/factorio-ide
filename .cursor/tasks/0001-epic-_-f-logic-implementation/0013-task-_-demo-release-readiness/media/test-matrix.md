# Матрица проверок: Примеры и готовность статического выпуска

Это план будущих проверок, а не результаты прогона. Общая [стратегия](../../media/testing-strategy.md).

| ID | Вход или действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| 01 | Обычный: каждый пример открыть и выполнить указанные тики | видимые результаты совпадают с эталонами. | Браузер / интеграция |
| 02 | Граница: приложение открыто по вложенному пути с завершающим `/` | ES-модули и ресурсы загружаются, навигация работает. | Браузер / интеграция |
| 03 | Ошибка: отсутствующий ресурс или неподдержанный режим | понятная диагностика; отсутствие сверки не представлено совместимостью. | Браузер / интеграция |
| 04 | Сценарий события: воспроизвести демонстрацию | события и выходы появляются на заявленных границах тиков. | Браузер / интеграция |
