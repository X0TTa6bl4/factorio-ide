# Матрица проверок: signals-networks

Будущие проверки, не отчёт о прогоне. Неподтверждённые игровые случаи отделять от проектной модели.

| ID | Вход / действие | Ожидаемый результат | Тип |
|---|---|---|---|
| NET-1 | Совпадающие type/name/quality: A=3 и A=7 | A=10 | unit |
| NET-2 | Разные type или quality при одинаковом имени | Разные каналы; normal по умолчанию | unit |
| NET-3 | A=3 и A=-3 | Канала нет, чтение 0 | unit |
| NET-4 | MAX+1, MIN−1, отрицательные итоги | MIN, MAX, отрицательные значения сохраняются | границы |
| NET-5 | R: A=10 B=4; G: A=3 C=7; все маски | Оба: A=13 B=4 C=7; каждый цвет отдельно; false/false пуст | unit |
| NET-6 | R A=3, G A=-3; маска обоих | A отсутствует в перечислении, чтение 0 | unit |
| NET-7 | Повторный провод, отдельные сети одного цвета | Нет дубля вклада и физического слияния отдельных сетей | интеграционный |
| NET-8 | null, чужая схема, неверный цвет или строка вместо сети | null допустим; неверные ссылки отклоняются атомарно | негативный |
| NET-9 | Попытка передать Each/Anything/Everything как канал | Метасигналы не являются обычными каналами | негативный |
