## Свидетельства и точность 16.11.2026

Разделять игровой результат и реализацию JS. Для произведения int32 использовать Math.imul либо BigInt.asIntN; проверять точный результат независимым BigInt-оракулом. Степень нельзя автоматически объявить Math.pow или целочисленной модульной степенью: актуальные крайние случаи в источниках не найдены, нужны эталоны из игры по [списку](../../../docs/specs/factorio/arithmetic.md).

Если после эталона выбран модульный алгоритм степени, ограничивать размер промежуточных чисел на каждом умножении; не вычислять огромный BigInt целиком. До подтверждения спорный случай имеет статус неподдержанного/модельного, а не успешной игровой совместимости.
