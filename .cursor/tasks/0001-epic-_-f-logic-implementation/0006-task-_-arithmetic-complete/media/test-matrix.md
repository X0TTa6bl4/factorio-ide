# Матрица проверок

A/B/C — разные обычные каналы; R/G — красный/зелёный вход. t+1 — следующая граница при подключённом выходе. Числовые ожидания ниже — модель спецификации, не результаты запуска игры. [Правила](../../../../docs/specs/factorio/arithmetic.md), [метасигналы](../../../../docs/specs/factorio/meta-signals.md), [совместимость](../../../../docs/specs/compatibility.md).

| Правило | Вход и настройка | Ожидание на t+1 |
|---|---|---|
| Операции | 7+3, 7-3, 7*3, 7/3, 7%3, 2^3 | 10, 4, 21, 2, 1, 8 |
| Знак и биты | -21/10, -13%3, -8>>1, 6 AND 3, 6 OR 3, 6 XOR 3, 3<<2 | -2, -1, -4, 2, 7, 5, 12 |
| int32 | MAX+1; MIN-1 | MIN; MAX |
| Точность умножения | MAX*MAX; MAX*2; MIN*(-1) | 1; -2; MIN по int32; проверка не должна терять младшие биты из-за промежуточного Number |
| Сбор результатов Each | A=MAX, B=1; Each+0 → C | C=MIN после суммирования по int32 |
| Маски | R:A=10,B=4; G:A=3,C=7; A(R)+A(RG)→D | D=23 |
| Пусто | A(false/false)+5→B | B=5; без выхода или порта пусто |
| Each | A=3,B=-2; Each*2→Each / →C | A=6,B=-4 / C=2 |
| Each | R:A=10,B=4; G:A=3,C=7; Each(RG)+0→Each | A=13,B=4,C=7 |
| Each | пустой вход; Each+1→Each | пусто |
| Отмена | R:A=3; G:A=-3; Each(RG)+0→Each | пусто по модели; нужен игровой fixture |
| Ошибки | два Each, выход Each без Each, Anything/Everything, смешанный Operand, дробь/NaN/вне int32, строковая операция, неверная сеть | диагностика без преобразования |

Параметризовать каждую операцию по знакам и границам; маски R/G/RG/нет; отсутствующий и нулевой канал; разные type/name/quality. Проверить Each справа и слева, совпадение выхода и входа и сбор с переполнением. Для /0, %0, MIN/-1, отрицательных и нулевых степеней, переполнения степени и сдвигов <0 или ≥32, Each(R)+A(G) и отмены цветов получить игровой fixture до выбора ожидания. Мутации арифметических операций и знаков должны обнаруживаться тестами.

Непроверенные игровые ветви допускаются к поддержке только после fixture и обновления спецификации; до этого требуется явная диагностика неподдерживаемого случая. Проверять атомарность ошибки после принятия общего контракта ошибок.

Перебрать варианты обоих операндов независимо: `Operand`, `OperandConst`, `null`; для `Operand` — все четыре маски и обычный сигнал/допустимый Each. Константы на обеих сторонах работают без изменений входных сетей. Невалидные формы (`{}`, лишнее поле, отсутствующий boolean, смешение `constant` с `signal`/цветами, нечисловая или бесконечная константа) отклоняются до исполнения; проверку повторить через конструктор и импорт. Отдельно проверить, что игровая степень не исполняется как JavaScript XOR.

| Дополнительное правило | Вход и настройка | Ожидание на t+1 |
|---|---|---|
| Сбор Each | A=1,B=1,C=1; Each*10→Each | A=10,B=10,C=10 |
| Сбор в один канал | тот же вход; Each*10→B | только B=30 |
| null и пустая маска | null+5→B после прежнего B=9 / A(false/false)+5→B | пустой вклад, прежний исчезает / B=5 |
| Не выбран return | A=3; A+2; return не выбран | пустой вклад |
