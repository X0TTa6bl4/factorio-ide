# Обзор проводов схемы

## Контекст

Страницы конфигурации, сетей и отладчика показывают имена портов по одному устройству. [0023](../0023-task-_-future-tools-scope/0000-future-tools-scope.md) принял обзор только для чтения. Данные обзора даёт [0024](../0024-task-_-circuit-structure/0000-circuit-structure.md). Контракт страницы — [дополнительные средства](../../../docs/specs/future-tools.md). Элементы брать из [библиотеки](../../../../ui/README.md).

## Цель

Страница `pages/structure/index.html` показывает отчёт `circuitStructure` и при ошибочном JSON сохраняет предыдущий успешный обзор.

## Границы

### Входит

- Страница, модуль отображения и браузерные проверки матрицы.
- Ссылка в общей навигации приложения.
- Пустое состояние, код ошибки, списки читателей и писателей, признак цикла и свидетель.

### Не входит

- Перетаскивание, запись координат, новая версия файла, шаг симуляции.
- Импорт blueprint и второй способ редактировать порты.
- Реализация `circuitStructure`: она входит в 0024.
