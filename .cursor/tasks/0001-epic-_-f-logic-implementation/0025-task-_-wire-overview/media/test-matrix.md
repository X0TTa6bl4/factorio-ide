# Матрица проверок: обзор проводов

Контракт страницы — [дополнительные средства](../../../../docs/specs/future-tools.md). Это план браузерных проверок задачи 0025, не отчёт о прогоне.

| ID | Действие | Ожидание |
|---|---|---|
| UI1 | Вставить корректный JSON с двумя сетями и свидетелем цикла | Имена, цвет, читатели, писатели и свидетель видны в порядке отчёта |
| UI2 | Оставить поле пустым при первом открытии | Текст «Схема не загружена», списков сетей нет |
| UI3 | После UI1 вставить `{` | Виден код `invalid-json`, имена предыдущего обзора остаются |
| UI4 | На загруженной странице нет кнопки шага, модуль страницы не вызывает `step` | Значения сигналов и номер тика не появляются |
