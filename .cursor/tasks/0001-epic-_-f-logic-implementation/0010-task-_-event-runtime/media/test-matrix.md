# Матрица событийного блока первого среза

Тесты проектной модели по [контракту](../../../../docs/specs/event-combinator.md) и [стратегии](../../media/testing-strategy.md); игровых результатов этот служебный тип не имеет. Ожидания ER-01…ER-24 выполнены 18.11.2026, фактический прогон — в [задаче](../0000-event-runtime.md).

| ID | Действие | Ожидаемые границы / ошибка | Уровень |
|---|---|---|---|
| ER-01 | init ставит A=2, Constant A=3 | На t0 A=5 при любой перестановке блоков | integration |
| ER-02 | readSignal/readSignals в init | Ошибка подготовки всего прогона, без частичного t0 | negative |
| ER-03 | main читает A на t и пишет B | Вход неизменяем; B виден на t+1, следующий вычислитель читает его на t+1 | trace |
| ER-04 | init A=2; pulse A=3 длительностью2 на 0→1 | Границы0/1/2/3:2/5/5/2; срок не зависит от main | trace |
| ER-05 | pulse duration1 из init | Вклад есть на0, отсутствует на1 | trace |
| ER-06 | hold A=2; pulse A=3 и A=4 одновременно | На границе пересечения A=9, сроки независимы | unit |
| ER-07 | set A=1,B=2; затем set A=3 | Удерживается только A=3, B удалён; другой цвет не изменён | contract |
| ER-08 | set signals:[] при активном pulse | Hold пустой, pulse продолжает действовать | contract |
| ER-09 | pulse→clear / clear→pulse в одном main | Первый порядок пуст; второй создаёт новый pulse | contract |
| ER-10 | set→pulse→set | Последний hold плюс действующий pulse; set не отменяет pulse | contract |
| ER-11 | red/green/both/false-false; неподключённый порт | Независимые цвета; false-false noop; нет вклада в неподключённую сеть | contract |
| ER-12 | Дубли/нулевая сумма/отрицательное количество в signals | int32-сумма; нулей нет, отрицательные сохраняются | unit |
| ER-13 | duration0/-1/1.5; meta; смешанные типы; неверный state | Ошибка шага, опубликованный checkpoint прежний | negative |
| ER-14 | every_tick / input_changed; оба входа изменены | Первый режим каждый тик; второй первый шаг и изменения; один main | integration |
| ER-15 | wakeAt99 и совпавшие input/message | Один main с tick99/nextTick100; результат на100 | integration |
| ER-16 | wakeAt прошлого/текущего из main; cancelWake будущего | Прошлое/текущее — ошибка; отменённый будущий запуск отсутствует | contract |
| ER-17 | send на0→1; mutate исходного data после send | Получатель видит копию на1; эффект его main на2 | integration |
| ER-18 | Несколько отправителей, перестановка массива | Порядок from ID/sequence и трасса неизменны; inbox потреблён один раз | property |
| ER-19 | Чужой/неизвестный peer, неверный message, send в init | Ошибка без частичного сообщения/старта | negative |
| ER-20 | Сбой после state/random/send/output/wake | Тик и все перечисленные состояния восстановлены вместе | integration |
| ER-21 | Reset/restore после pulse, message и wake | Reset повторяет init; restore не вызывает init и повторяет продолжение | integration |
| ER-22 | Возвращён Promise из main | Явная ошибка синхронного контракта; поздние эффекты не принимаются | contract/browser |
| ER-23 | Один seed и управляемые state/RNG, повтор прогона; восстановленный x=1 | Та же последовательность; первые uint32:270369/67634689/2647435461; вывод seed — по FNV-1a из контракта | unit/property |
| ER-24 | Цикл сообщений двух сценариев | По одной границе на доставку, без рекурсии в одном step | integration |
