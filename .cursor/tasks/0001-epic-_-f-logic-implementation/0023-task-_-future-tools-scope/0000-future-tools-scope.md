# Решение об инструментах будущих этапов

## Контекст

Этап 6 после [сохранения схем](../0017-task-_-project-persistence/0000-project-persistence.md) и [совместной проверки комбинаторов](../0012-task-_-combinator-integration/0000-combinator-integration.md). К 19.11.2026 есть текст конфигурации, страницы сетей, отладчика и файла `f-logic-project` версии 1. Контракт решения — [дополнительные средства](../../../docs/specs/future-tools.md).

## Цель

Принято и документировано решение о целесообразности и границах дополнительных инструментов.

## Границы

### Входит

- Сценарии визуальных проводов, импорта и экспорта blueprint и анализа; матрица поддержанного, отклонённого и требующего сверки.
- Задачи только на принятый объём: [0024](../0024-task-_-circuit-structure/0000-circuit-structure.md) и [0025](../0025-task-_-wire-overview/0000-wire-overview.md).

### Не входит

- Реализация обзора, разбора и любых других инструментов.
- Изменение игрового ядра и публикация.
- Задача на импорт или экспорт blueprint.

## Требования и ограничения

- HTML, CSS, обычный JavaScript и нативные ES-модули; без обязательных TypeScript, сборщика и фреймворка. Устанавливаемые инструменты разработки и проверки запускаются через Docker задачи 0001, не через host npm.
- Движок независим от DOM и таймера, описание схемы отделено от состояния. Игровая совместимость чертежа не заявлена: справочник 2.1.24 прочитан, игровой прогон не выполнялся.
