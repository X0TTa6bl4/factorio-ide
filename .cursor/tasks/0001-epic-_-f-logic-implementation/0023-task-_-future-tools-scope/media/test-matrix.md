# Матрица проверок: Решение об инструментах будущих этапов

Общая [стратегия](../../media/testing-strategy.md). Контракт — [дополнительные средства](../../../../docs/specs/future-tools.md).

| ID | Вход или действие | Ожидаемый результат | Уровень | Результат 19.11.2026 |
|---|---|---|---|---|
| 01 | Обычный: сценарий создания сложной схемы | Решение об интерфейсе обосновано наблюдаемой потребностью | Документ | Текст конфигурации уже задаёт общую сеть и петлю. Отладчик, сети и конфигурация показывают порты по одному. Принят обзор только для чтения, задача 0025. Редактор холста вне объёма |
| 02 | Граница: blueprint содержит устройства или данные вне модели | Матрица явно определяет отказ, ограничение либо отложенное исследование; потери не скрываются | Документ | Импорт и экспорт чертежа вне объёма, задачи нет. Несопоставленные разъёмы и `control_behavior` отмечены как отдельная сверка. Условие любого будущего импорта — отказ всего чертежа со списком причины |
| 03 | Ошибка: некорректный или несовместимый blueprint | Выбранный контракт диагностики исключает молчаливую порчу схемы | Контейнер | Образ `f-logic-dev:1.56.1`, Node v22.20.0. Строка `0eNq` → `invalid-json`; JSON `{blueprint:...}` → `foreign-format`; `{` → `invalid-json`. Имя открытой схемы не изменилось |
| 04 | Анализ: предложенная проверка сложной сети | Указаны вход, ожидаемый вывод и ограничения; семантика не объявлена проверенной без сверки | Документ | Вход — документ версии 1. Выход — сети, читатели, писатели, `cyclic` и один свидетель. Задержка игры и текст `main` в отчёт не входят. Задача 0024 |
