# Матрица проверок

A/B/C — разные обычные каналы; R/G — красный/зелёный вход. t+1 — следующая граница при подключённом выходе. Числовые ожидания ниже — модель спецификации, не результаты запуска игры. [Правила](../../../../docs/specs/factorio/constant.md), [метасигналы](../../../../docs/specs/factorio/meta-signals.md), [совместимость](../../../../docs/specs/compatibility.md).

| Правило | Настройка | Ожидание |
|---|---|---|
| Источник | enabled, A=5 | A=5 на начальной границе и после 10 шагов, не 50 |
| Секции | активные A=2 и A=3 | A=5; отключение второй даёт A=2 |
| Выключение | enabled=false | пустой вклад |
| Нормализация | A=2 и A=-2; MAX и 1 | пусто; MIN соответственно |
| Профиль | одинаковое имя при разных type или quality | раздельные каналы |
| Группа | две секции с общей группой A=2; изменить группу на A=3 | оба использования отражают изменение по согласованной границе |
| Фильтр | min=5, max=10 | A=5, не 10 |
| Ошибки | неверный сигнал, сеть, поле, нечисловое значение | диагностика без молчаливого преобразования |

Параметризовать пустые секции, обе сети, одинаковые и разные сигналы, отрицательные и нулевые значения, активность и изменение группы. До ожиданий для дробных/отрицательных множителей, округления и переполнения сохранить игровой fixture с версией; согласовать идентичность групп, удаление и момент вступления изменений в силу.

Непроверенные игровые ветви допускаются к поддержке только после fixture и обновления спецификации; до этого требуется явная диагностика неподдерживаемого случая. Проверять атомарность ошибки после принятия общего контракта ошибок.

Проверить пустую секцию, один фильтр с множителем 1 и несколько секций с одинаковым ключом; отключение источника подавляет все секции, а отключение секции — только её вклад. Изменение общей группы проверить для каждого использования; момент публикации согласовать с tick-engine. Множители, для которых нет подтверждённого игрового правила, не считать поддержанными без fixture.
