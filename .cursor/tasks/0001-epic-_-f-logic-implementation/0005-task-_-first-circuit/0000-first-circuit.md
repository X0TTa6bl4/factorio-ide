## Цель

Первый браузерный контур выполняет минимальные Constant/Arithmetic и событийный сценарий по общим тикам, показывает сети и ошибки.

## Границы

### Входит

- Минимальный Constant по API: enabled:boolean, signals:[{signal,constant}], одна неименованная секция ×1, без входов; проверить и enabled:false. Минимальный Arithmetic: сложение, обычный сигнальный и числовой операнды, обычный выход. Проверка конфигурации, подключение к движку, минимальная статическая страница. Полные секции Constant и режимы игровых комбинаторов 0006–0009 остаются отдельными задачами. Событийный блок уже входит сюда по результатам задач 0010/0011.

### Не входит

- Публикация, коммит, произвольные дополнительные устройства и работа соседних задач. Для конечного пользователя прикладной сервер не нужен.

## Критерии приёмки

- [x] При A=3 и A+2→B на t=0 виден A=3, на t=1 B=5; reset повторяет t=0. Ошибочная конфигурация отклоняется атомарно, неподдержанный режим диагностируется.
- [x] Когда вычислитель перестаёт выдавать вклад B, после публикации он исчезает; без других источников канал B отсутствует и читается как 0.
- [x] Выполнены применимые проверки из матрицы; неподтверждённые игровые случаи отмечены отдельно.

## Сборка и событийное окружение

Сети и устройства получает единый Circuit; страница и тесты не создают собственный граф. Использовать профиль base и зарегистрированные токены. После каждого успешного await step показывать только опубликованную границу.

Дополнительные предшественники: [0010](../0010-task-_-event-runtime/0000-event-runtime.md) и [0011](../0011-task-_-event-script-editor/0000-event-script-editor.md). Основные арифметические тесты и шаг 0100 можно готовить параллельно; готовность всего первого среза требует реального Worker.

- [x] Событийный pulse меняет вход арифметического на заданной границе, результат вычислителя появляется ещё через тик.
- [x] Сообщения между двумя сценариями видны только на следующей границе; перестановка устройств сохраняет трассу.
- [x] Ошибка и timeout не публикуют частичный шаг, reset повторяет границу 0.
- [x] Страница явно показывает, что Constant/Arithmetic представлены минимальным срезом, а тесты — проектной моделью.
