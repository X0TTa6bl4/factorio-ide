# Матрица проверок: Редактор конфигурации

Это план будущих проверок, а не результаты прогона. Общая [стратегия](../../media/testing-strategy.md).

| ID | Вход или действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| 01 | Обычный: `Signal.Logistic.wooden_chest`, допустимая операция и сеть своего цвета | подсказки доступны, схема проходит проверку. | Браузер / интеграция |
| 02 | Граница: `{red:false,green:false,signal:…}` допустим; `null` операнда остаётся незаданным и не заменяется нулём. | Результат соответствует описанному контракту. | Браузер / интеграция |
| 03 | Ошибка: `{constant:5,signal:…}`, отсутствующий `green`, строка `"5"`, дробное или вне int32 | точные диагностики без преобразований. | Браузер / интеграция |
| 04 | Ошибка: `Signal.Meta.signal_each` в обоих операндах арифметического или недопустимый выход сравнивающего | указаны связанные поля, запуск запрещён. | Браузер / интеграция |
| 05 | Ошибка: вызов произвольной функции, побочное присваивание вне разрешённых деклараций или иной эффект в конфигурации | отклонение согласованной грамматикой; разрешённые `new Arithmetic({...})`, ссылки и декларации конфигурации проверяются отдельно. | Браузер / интеграция |
| 06 | Профиль: недоступный сигнал или качество не предлагается и диагностируется при вставке. | Результат соответствует описанному контракту. | Браузер / интеграция |
| 07 | Одинаковая вложенная конфигурация в виджете, подсказках и runtime | все три средства одинаково принимают допустимые и отклоняют недопустимые варианты. | Браузер / интеграция |
