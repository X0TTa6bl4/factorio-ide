# Матрица проверок: Локальное сохранение и перенос схем

Это план будущих проверок, а не результаты прогона. Общая [стратегия](../../media/testing-strategy.md).

| ID | Вход или действие | Ожидаемый результат | Уровень |
|---|---|---|---|
| 01 | Обычный: схема с общими сетями, качеством и сценарием | экспорт/импорт сохраняет идентичность ссылок и содержимое. | Браузер / интеграция |
| 02 | Граница: циклическая обратная связь | файл конечен, после чтения все ссылки восстанавливаются по ID. | Браузер / интеграция |
| 03 | Ошибка: повреждённый JSON, дубли ID или отсутствующая ссылка | точная ошибка, старая схема остаётся открытой. | Браузер / интеграция |
| 04 | Ошибка: чужой формат, будущая версия или неподдержанный профиль | явный отказ без частичного применения. | Браузер / интеграция |
| 05 | Ошибка: заполненная квота или отказ storage | сообщение; данные в памяти и ранее сохранённая версия не повреждены. | Браузер / интеграция |
| 06 | Безопасность: импорт сценария с побочным эффектом | при импорте эффект отсутствует; выполнение лишь через явное действие по правилам событийного блока. | Браузер / интеграция |
| 07 | Коллизия имени при импорте | согласованная политика разрешения применяется явно; существующая схема не перезаписывается молча. | Браузер / интеграция |
| 08 | Устаревший ID сети или устройства в ссылке | ошибка с указанием ссылки, загрузка не применяется атомарно. | Браузер / интеграция |
