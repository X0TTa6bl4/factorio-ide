# Первый эпик правок: редактор кода как основное рабочее пространство

## Кратко

При открытии приложения пользователь сразу получает редактор обычных комбинаторов, управление симуляцией и просмотр сигналов сетей. Конфигурация упрощена до `Arithmetic({...})`, автодополнение работает непосредственно в коде, вспомогательные средства доступны по запросу.

## Контекст

Запрос от 19.11.2026 — составить задачи по девяти замечаниям, без изменения кода. Пользователь сообщил о завершении предыдущих работ; этот эпик не меняет их статусы. Незакоммиченные изменения проекта сохранять.

Фактически найдены: стартовая страница примеров `index.html`, редактор `pages/configure/`, события `pages/event/`, грамматика `src/config-grammar.js`, модель редактора `src/config-editor.js`, подсветка `pages/code-paint.js`, библиотека `ui/`. В `pages/configure/page.js` подсказки подключены к отдельным полям, но обработчик основного textarea только обновляет текст и отображение. `.fl-editor--paint .fl-textarea:focus-visible` задаёт янтарную рамку. Это результаты чтения кода; браузерное воспроизведение при планировании не выполнялось.

[Скриншот пользователя](media/unwanted-page-header.png) показывает ненужную верхнюю часть: служебная надпись, Base, крупный заголовок, техническое пояснение и большой баннер версии. Требование убрать её относится ко всем экранам.

## Цель

Из корневой ссылки можно написать конфигурацию без обязательных имён устройств и `new`, получить подсказки у курсора, запустить или пошагово выполнить текущий текст и увидеть сигналы по сетям, оставаясь внутри рабочего пространства размером с окно браузера.

## Границы

### Входит

- Девять замечаний пользователя и расширение общей библиотеки UI, необходимое для их выполнения.
- Корневая страница и все рабочие `pages/*/index.html`; примеры `ui/index.html` и `ui/workspace.html` приводятся к новым правилам без потери каталога и исходников.
- Сохранение существующих возможностей через компактные команды, навигацию и раскрываемые панели.

### Не входит

- Реализация во время составления задач, установка инструментов, коммит и публикация.
- Копирование дизайна VS Code, внедрение полного VS Code/Monaco/CodeMirror, TypeScript, сборщика или фреймворка без отдельного согласования.
- Изменения игровой семантики, графический редактор схемы, новый язык событийных сценариев.

## Решения по девяти замечаниям

1. Корневая ссылка сразу открывает редактор обычных комбинаторов; примеры — вторичное действие.
2. Остаётся явная кнопка «Событийные комбинаторы» на отдельную страницу, с обратным переходом.
3. Код — крупнейшая постоянная область. Постоянно доступны управление симуляцией, текущий тик и область сигналов сетей. Формы, список устройств и подробная диагностика вторичны; ошибка обозначается компактно с доступом к деталям.
4. Желтая рамка по клику в код удаляется. Клавиатурный фокус остаётся различимым и не перекрывает символы.
5. Автодополнение действует в самом коде у курсора, включая незавершённый текст; отдельный поиск в инспекторе его не заменяет.
6. Основная форма — `Arithmetic({...})`, аналогично Constant/Decider/Selector, с их реальными полями. Обязательные `arithmetic adder = new`, ручная регистрация и имя каждого устройства убираются.
7. Страница занимает доступный viewport, а не одно фиксированное число пикселей; прокрутки находятся внутри окон. Верхняя часть со скриншота убирается везде. Версия, профиль и честные ограничения совместимости доступны через компактную справку, без большого постоянного баннера.
8. Видимые стандартные выпадающие select заменяются общим кастомным элементом на всех экранах и в образцах. Нативный файловый диалог импорта к этому требованию не относится.
9. VS Code — ориентир взаимодействия: приоритет кода, контекстное дополнение, клавиатура, сворачиваемые панели. Упомянутая реализация в GitHub не идентифицирована и не задаёт библиотеку. Дизайн f logic сохраняется; интеграция с GitHub не требуется.
