# Простой синтаксис конфигурации

## Контекст

`src/config-grammar.js` требует тип, имя, `=` и `new`; стартовый пример `src/config-editor.js` закрепляет эту форму.

Родитель: [первый эпик правок](../0000-editor-first-revision.md). Все общие ограничения и решения родителя действуют для этой задачи.

## Цель

Обычные комбинаторы задаются вызовами `Тип({...})` и собираются в общую модель без исполнения произвольного JavaScript.

## Границы

### Входит

- Поддержать пример пользователя без предварительных wire и имени устройства:

```js
Arithmetic({
  red_input: red_1,
  green_output: green_1,
  left_operand: { red: true, green: true, signal: Signal.Logistic.wooden_chest },
  right_operand: { constant: 2 },
  operation: Arithmetic.Operation.SUM,
  return: Signal.Logistic.wooden_chest
})
```

- Та же форма для Constant, Decider, Selector; реальные поля, маски, операции и профиль сохраняются. Пометка PHP у примера не меняет согласованный JavaScript-стек.
- Валидные ссылки red_/green_ в портах разрешать через общий Circuit: повтор имени означает ту же сеть; цвет и зарезервированные red_new/green_new проверяются. В готовом документе сеть восстанавливается из порта без служебного wire. В процессе ввода создание через подсказку требует подтверждения; отмена не создаёт сеть. Не создавать сущности по неизвестным именам вне портов.
- Синтаксис остаётся декларативным: только разрешённые формы, без eval, Function и произвольных вызовов. Внутренние классы движка можно сохранить.
- Определить идентичность безымянных устройств: изменение поля и вставка соседнего устройства не переназначают ID и существующие ссылки. Служебные ID не требуют ручного ввода. Для явных ссылок сохранить необязательный именованный путь, не усложняя основной пример.
- Прежний синтаксис должен читаться или явно безопасно мигрировать: не терять устройства, ID, сети, группы и peers при импорте/экспорте. Старые примеры открываются, новые показывают простой синтаксис.
- Согласовать грамматику, модель, подсветку, диагностику, сериализацию и основные спецификации. Свободный JS событий не заменять конфигурационной грамматикой.

### Не входит

- Работы вне родительского эпика, публикация, изменения игровой семантики.
- Реализация во время составления задач.
