# Автодополнение непосредственно в коде

## Контекст

В `src/config-editor.js` есть suggestions/applySuggestion, но textarea configure не открывает меню. Поиск в инспекторе не заменяет дополнение в коде.

Родитель: [первый эпик правок](../0000-editor-first-revision.md). Все общие ограничения и решения родителя действуют для этой задачи.

## Цель

При наборе конфигурации подсказки у курсора учитывают поле и принимаются без перехода в формы.

## Границы

### Входит

- Контекст по курсору и незавершённому тексту: имя типа, допустимые ключи и вложенные операнды, сеть нужного цвета, Signal/Quality, операция владельца, допустимые устройства/сценарии.
- Автоматическое меню при префиксе/точке и ручной вызов Ctrl+Space. Корректность всего документа не обязательна. Не предлагать недопустимые метасигналы и операции другого типа.
- Общий индекс, профиль каталога, MRU и правила редактора; red_new/green_new и подтверждение пользовательского имени работают в тексте, служебный вариант сразу заменяется настоящим именем. Каталоговые сущности через _new не создаются.
- Меню у каретки учитывает прокрутку, край окна и перемещение курсора. Стрелки выбирают, Enter/Tab принимают открытый выбор, Escape закрывает. При закрытом меню обычное поведение редактора сохраняется. Мышь не теряет место вставки.
- Заменять актуальный диапазон токена без повреждения соседнего текста, отступов и курсора; одна подстановка отменяется одним undo. Обработать середину строки, выделение, комментарии и длинные строки.
- Перед применением проверять revision/контекст/диапазон. Устаревший ответ не меняет текст или сети. Полная проверка перед запуском сохраняется.
- Страница событий использует общий элемент редактора/меню с подсказками реально поддержанного событийного API; не обещать полный JS language server и не переносить туда грамматику конфигурации.

### Не входит

- Работы вне родительского эпика, публикация, изменения игровой семантики.
- Реализация во время составления задач.
