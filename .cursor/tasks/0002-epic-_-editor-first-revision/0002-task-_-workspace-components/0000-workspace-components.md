# Общие компоненты компактного рабочего пространства

## Контекст

В `ui/components/` уже есть редактор, toolbar, таблица, signal/network picker; fields и страницы используют нативный select. Фокус редактора рисует янтарную рамку.

Родитель: [первый эпик правок](../0000-editor-first-revision.md). Все общие ограничения и решения родителя действуют для этой задачи.

## Цель

Общие компоненты поддерживают компактные панели, кастомный выбор и меню автодополнения с полноценной клавиатурой.

## Границы

### Входит

- Расширить code-editor, simulation-toolbar, signal-table, diagnostics и dialog. Добавить общий кастомный select/combobox, сворачиваемую панель и меню подсказок; это будущие компоненты, имена файлов выбрать при реализации.
- Кастомный выбор: подпись, значение, placeholder, disabled, ошибка, пустая выдача, длинный список, активный и выбранный пункт; поиск для больших каталогов. Клавиатура: открытие, стрелки, Home/End, Enter, Escape, Tab; клик снаружи и предсказуемый возврат фокуса. Корректные ARIA-роли и прежнее изменение модели при выборе.
- Сворачиваемые панели: заголовок-кнопка, aria-expanded, Enter/Space и безопасное перемещение фокуса при скрытии содержимого.
- Редактор занимает доступный остаток высоты, панели имеют собственные прокрутки. Меню подсказок не обрезается контейнером и остаётся в viewport.
- Удалить желтую рамку по клику, сохранить спокойный клавиатурный фокус, каретку, выделение и синхронизацию слоя подсветки/номеров строк при скролле. Не отключать фокус глобально.
- Все состояния добавить в `ui/index.html`, сборку показать в `ui/workspace.html`, обновить `ui/README.md`; стили и поведение не копировать по страницам.

### Не входит

- Работы вне родительского эпика, публикация, изменения игровой семантики.
- Реализация во время составления задач.
