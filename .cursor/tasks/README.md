# Локальные задачи

Создавать задачи по запросу, используя `task-workflow-ru` и его шаблоны.

Формат: `NNNN-{epic|task|bug}-{jira|_}-{slug}/0000-<slug>.md`.
В эпике — директории дочерних задач с собственной нумерацией `0001+`.
В задаче шаги — `0100`, `0200`; fix-up — `0101`, `0201` и т. д.
`.task-sequence` хранит последний выданный номер верхнего уровня.

Артефакты задачи — в её `media/`. Архивировать только по поручению, номера не переиспользовать.
