# Форматирование, Tab и единый порядок полей

## Контекст

Замечания №7, 11 из [записей редактора](../media/editor/notes.md). Отдельного форматтера сейчас нет; порядок полей задан `DEVICE_FIELDS` в `src/config-completion.js`. Текущий Tab принимает подсказку, что конфликтует с новым требованием табуляции.

## Цель

Хоткей приводит документ к единому виду без изменения смысла, Tab вставляет табуляцию, порядок полей согласован с созданием объектов.

## Границы

### Входит

- Создать независимый от DOM `src/config-format.js`: использовать токены/диапазоны `src/config-grammar.js`, форматировать весь документ с отступом U+0009. Сохранять комментарии, строки, значения, порядок деклараций и элементов массивов; пользовательский текст не исполнять.
- Вынести порядок полей `DEVICE_FIELDS` из `src/config-completion.js` в новый общий `src/config-schema.js`; применять в подсказках, структурной вставке и форматировании. За исходный порядок принять текущие массивы DEVICE_FIELDS; вложенные типовые объекты упорядочивать по метаданным текущих контекстов. Не дописывать отсутствующие поля, не сортировать произвольные ключи `state`/пользовательских данных, неизвестные поля сохранять в исходном относительном порядке после известных.
- Синтаксически неполный/ошибочный документ оставлять без изменения текста и истории, причину показывать через существующую диагностику. Комментарии к переставляемым полям сохранять при соответствующих полях. Повторное форматирование не меняет результат.
- В `pages/configure/page.js` добавить Option+Command+L на macOS и Ctrl+Alt+L на Windows/Linux только при фокусе `#document`. В `#document-hint` обоих HTML указать сочетание и «Tab — отступ, Enter — выбрать подсказку». Новая кнопка не нужна.
- Форматирование — одна транзакция общего редактора; сохранить позицию у соответствующего токена и прокрутку по возможности. Undo возвращает весь исходный документ, redo — результат.
- В `pages/caret-complete.js` перестать принимать подсказку по Tab. В textarea Tab заменяет выделение одним U+0009; Enter/мышь принимают пункт; Shift+Tab уходит к предыдущему элементу. В обычных полях Tab сохраняет переход фокуса. Для сетевого токена сначала завершить имя по 0003, затем добавить табуляцию в той же транзакции.
- Синхронизировать `tab-size: 2` в `ui/styles/components.css`, textarea, слое подсветки и измерении каретки; проверить `pages/code-paint.js`, `pages/caret-complete.js`. Не менять номер строки/позицию меню ошибочно из-за табуляции.
- Обновить `ui/components/code-editor.html`, `ui/README.md`, `.cursor/docs/specs/editor.md`. Явно заменить прежнее правило Tab=принять на новое; UI — по [проекту](../media/ui/design.md).
