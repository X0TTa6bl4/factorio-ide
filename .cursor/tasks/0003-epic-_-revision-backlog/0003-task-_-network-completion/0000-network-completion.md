# Подсказки сетей и завершение ввода нового имени

## Контекст

Замечания №3, 4 из [записей редактора](../media/editor/notes.md). `suggestionItems` в `src/network-document.js` добавляет пункт `create` и ранжирует совпадения по MRU. Пользователь уточнил: служебный пункт показывать только при совпадении с текстом, Tab тоже завершает имя.

## Цель

Точное совпадение сети имеет приоритет, новое имя завершается через Esc, клик или Tab без отдельного пункта «Создать».

## Границы

### Входит

- В `src/network-document.js` удалить пользовательский пункт `kind: create`. Порядок существующих сетей своего цвета: точное совпадение, затем совпадения по префиксу; при равной близости — MRU и детерминированный порядок имени. Служебный пункт располагается после существующих совпадений.
- `red_new`/`green_new` — служебные действия генерации свободного имени своего цвета. Они видны только если начинаются с введённого префикса: `red_` показывает `red_new`, `red_t` — нет; пустой запрос допускает пункт своего цвета. Буквальное создание этих сетей запрещено.
- В `pages/caret-complete.js` различать причины закрытия. В `pages/configure/page.js` завершать актуальный сетевой токен по Esc, клику в другое место (включая тот же textarea) и Tab. По Tab сначала завершить имя, затем вставить табуляцию по 0005, не принимать активную подсказку вместо введённого имени.
- Корректное отсутствующее имя своего цвета регистрировать через общий `src/config-editor.js`; существующее использовать без дубля. Пустое/неполное имя, чужой цвет, `null` и произвольные строки не создавать как пользовательские сети. При ручном завершении точного `red_new`/`green_new` выполнять служебное действие с генерацией обычного свободного имени, не регистрировать слово `_new`.
- Скрытие меню из-за пустой выдачи/прокрутки/перерисовки само по себе не завершает ввод. Esc/клик/Tab работают и при пустой выдаче, независимо от наличия открытого DOM-меню.
- Создание и подстановка — одна транзакция общей истории; завершение по Tab вместе с табуляцией также отменяется целиком. Исключить двойную регистрацию от pointerdown/selectionchange/blur и применение устаревшего anchor.
- В формах `#network-query`/`#network-results` применить тот же список и завершение по Esc/уходу из поля/Tab; здесь Tab сохраняет обычный переход фокуса. Обновить `#network-help` в `index.html` и `pages/configure/index.html` и библиотечный `network-picker.html`.
- Проверить потребителей общего `suggestionItems` в `src/network-editor.js` и `pages/networks/page.js`, не менять их поведение случайно; покрыть затронутый контракт.

### Не входит

- Переименование существующих сетей, правила тика; реализация при подготовке задачи.

- [x] Невалидное имя и устаревшая подсказка не создают сеть и не меняют другое место документа.
