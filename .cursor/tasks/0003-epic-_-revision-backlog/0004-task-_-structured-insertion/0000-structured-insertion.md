# Пошаговая вставка класса, параметра и значения

## Контекст

Замечания №8, 10 из [записей редактора](../media/editor/notes.md). Требуется не просто заменить токен, а сформировать структуру и продолжить подсказки в новой позиции.

## Цель

Выбор класса и полей создаёт каркас документа и сразу предлагает следующий допустимый ввод в правильном месте.

## Границы

### Входит

- В `src/config-completion.js` описать результат структурной вставки: текст, диапазон замены, позиция каретки, следующий контекст. В `src/config-editor.js` применять его атомарно с проверкой ревизии.
- В `pages/configure/page.js` после выбора Arithmetic вставлять пустой многострочный объект:

```js
Arithmetic({

})
```

- Пустая строка содержит одну табуляцию, каретка после неё. Сразу открыть меню допустимых полей с пустым запросом. Аналогично Constant, Decider, Selector; для иных существующих конструкторов сохранить корректный синтаксис, например `new`, если он требуется грамматикой.
- При принятии имени поля вставлять `red_input: ,`, каретка после пробела и перед запятой. Не удваивать уже существующие двоеточие/запятую при исправлении поля. Сразу открыть меню значений этого поля.
- После принятия завершённого значения перенести каретку на следующую строку с тем же отступом и показать оставшиеся допустимые поля текущего объекта. Уже заданные поля не предлагать повторно.
- Выбор промежуточной группы Signal продолжает значение; к следующему полю переходить только после законченного листа. Вложенные объекты и массивы сначала завершаются внутри себя, без преждевременного ухода к родительскому полю.
- В `pages/caret-complete.js` поддержать открытие следующего списка после успешного commit: нынешнее безусловное закрытие не должно скрывать новое меню. Enter/мышь принимают пункт, Tab работает по 0005.
- Использовать библиотечные состояния `code-editor.html` и `suggest.html` из 0001 и [проект интерфейса](../media/ui/design.md). Порядок полей и отступы едины с 0005; отдельный компонент редактора не создавать.

### Не входит

- Выполнение пользовательского JS, заполнение всех параметров значениями по умолчанию; реализация при подготовке задачи.
