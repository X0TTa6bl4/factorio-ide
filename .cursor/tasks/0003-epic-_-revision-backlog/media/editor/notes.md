- **2026-11-21** — (1) В выпадающем меню подсказок по операции заменить слово «Operation» на знаки: `>`, `<`, `=` и т.д. То же для операций арифметического комбинатора.

- **2026-11-21** — (2) Подсказки должны появляться не только при вводе нового символа, но и при стирании.

- **2026-11-21** — (3) При вводе имени сети `red_new` пункт виден вверху только пока введено `red_`; при продолжении ввода пункт пропадает. При `red_t` не виден `red_new`, зато видны предложения задать `red_t`, `red_test` и т.д. В начале списка — самые близкие по совпадению. Если введено `red_t` и есть `red_t` и `red_ta`, вверху должен быть `red_t`. `red_new` и `<color>_new` — оба системные стопы; при вводе `<color>_new` не должна создаваться сеть с именем `<color>_new`.

- **2026-11-21** — (4) Убрать явное предложение «создать несуществующую сеть». Пример: есть `red_limit`, пользователь хочет `red_limi` — сейчас нужно прокрутить до пункта создания `red_limi`; этого пункта больше не должно быть. Новая сеть создаётся, когда исчезает выпадающая подсказка: Esc или клик курсором в другом месте.

- **2026-11-21** — (7) В окне редактора: хоткей форматирования кода (`Opt+Command+L`, адаптировать под Windows); по Tab — вставка табуляции.

- **2026-11-21** — (8) При вводе имени параметра (напр. `red_input`) после ввода автоматически добавлять двоеточие и запятую; курсор — после двоеточия и пробела, но перед запятой; сразу показывать выпадающую подсказку, что можно ввести в поле. При выборе пункта — переход на следующую строку и подсказка со всеми параметрами объекта.

- **2026-11-21** — (9) Логика подсказок для точечной нотации: при вводе `Signal.` после точки в списке только члены (`Logistic` и др.), без префикса `Signal.`; то же для выбора конкретного сигнала.

- **2026-11-21** — (10) После выбора `Arithmetic` (и аналогично — какой комбинатор создаём) вставлять:

```
Arithmetic({

})
```

Курсор с отступом между `{}`; сразу выпадающее меню с именами параметров.

- **2026-11-21** — (11) При форматировании кода имена параметров должны упорядочиваться так же, как при дефолтном создании объекта класса (задуманный порядок полей).
