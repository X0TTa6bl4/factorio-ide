## Редактор и правая колонка — замечание 5

На `index.html` и `pages/configure/index.html` внутри `.fl-editor-stage` оставить слева единственную панель «Код», справа добавить `aside.fl-editor-inspector` с доступным именем «Сети и настройки». Переместить в него существующие панели целиком, сохранив ID и обработчики. Порядок сверху вниз:

```text
Панель управления: … Сброс [↶] [↷] …
┌──────────────────────────┬──────────────────────┐
│ Код                      │ Сети                 │
│                          │ ▸ Устройства         │
│                          │ ▸ Формы              │
│                          │ ▸ Диагностика        │
└──────────────────────────┴──────────────────────┘
```

Удалить опустевший нижний `.fl-screen__drawers` только с этих двух страниц. Переносить секции, содержащие `devices-toggle`, `forms-toggle`, `diagnostics-toggle`, вместе с их содержимым, а не только заголовки. Сохранить начальное закрытое состояние. Открытие диагностики кнопкой `#error-jump` раскрывает и прокручивает нужную секцию справа; фокус и переход к месту ошибки в коде сохраняются.

На ширине >900 px использовать существующее соотношение колонок 2:1 и минимальную ширину правой 16rem. Код и инспектор прокручиваются независимо; заголовки не получают фиксированных координат. Таблица сетей прокручивается внутри `#signal-scroll`, вся колонка — при суммарной нехватке высоты. Не допускать прокрутки документа и вытеснения редактора при раскрытии форм.

До 900 px две строки: код сверху, тот же инспектор снизу, в соотношении оставшейся высоты 1.25:0.75, как в текущем адаптивном каркасе. Внутри инспектора порядок остаётся «Сети → Устройства → Формы → Диагностика»; горизонтальной второй колонки нет. Новые переключатели панелей не требуются.

Образец этой композиции поместить в новый `ui/components/editor-inspector.html`, зарегистрировать в `ui/index.html`, встроить справа в `ui/workspace.html`. Это новый составной элемент из существующих панелей, таблицы и форм; отдельную систему компонентов не вводить.

## Отмена и повтор — замечание 6

На двух адресах редактора заменить содержимое `#undo` и `#redo` двумя зеркальными SVG стрелками, используя `.fl-button--icon`. Положение сохранить: сразу после `#reset`, сначала отмена, затем повтор. Размеры и интервалы взять у существующего варианта кнопки. SVG декоративные, `aria-hidden="true"`; доступные имена кнопок — «Отменить правку» и «Повторить правку».

Новый элемент `ui/components/tooltip.html`: компактная подсказка с текстом действия и сочетанием клавиш; поверхность, рамка, радиус и шрифт из `tokens.css`, отступ 6px 8px, зазор от кнопки 6px. Текст: «Отменить правку · ⌘Z» и «Повторить правку · ⇧⌘Z» на macOS; «Отменить правку · Ctrl+Z» и «Повторить правку · Ctrl+Y» на Windows/Linux. Повтор дополнительно доступен через Ctrl+Shift+Z. Показывать при наведении и фокусе клавиатурой, скрывать по уходу указателя/фокуса и Escape; Escape здесь только скрывает tooltip. Подсказка без интерактивного содержимого, не получает фокус, `role="tooltip"`, связь с кнопкой через `aria-describedby`, не обрезается прокруткой и не выходит за viewport. Для disabled кнопки обёртка сохраняет возможность показать описание наведением; доступное имя остаётся у кнопки.

Демонстрацию обеих кнопок, disabled, hover/focus и длинного текста включить в `buttons.html` и новый фрагмент `tooltip.html`. Зарегистрировать tooltip в каталоге. Общее поведение — `ui/scripts/widgets.js`, оформление — `ui/styles/components.css`; рабочая страница задаёт только действие и платформенный текст.

## Подсказки — замечания 1–4, 8–10

Список остаётся у каретки и использует `.fl-suggest`. После точки основная подпись содержит только оставшийся путь: `Signal.` → `Logistic`, далее → дочерний сегмент. Вставка достраивает полный корректный путь без дублирования уже введённого. Не путать отображаемую подпись с идентификатором вставки.

У операций заменить вторичную подпись `Operation` знаком соответствующего действия; основную подпись оставить именем члена, а после точки скрывать уже набранный префикс. Например после `Decider.Operation.`: `GT` с подписью `>`, `EQ` с подписью `=`; после `Arithmetic.Operation.`: `SUM` с подписью `+`. Для всех поддерживаемых операций явно определить обозначение по существующему каталогу; не придумывать знак для режимов Selector. Это изменение представления, синтаксис API остаётся прежним.

В `suggest.html` добавить образцы операций, дочерних сегментов Signal, пустого значения поля и параметров пустого объекта. В `network-picker.html` убрать строку «Создать <введённое имя>», описать завершение ввода через Esc/клик/Tab и служебные действия `red_new`/`green_new`. Уточнение пользователя 21.11.2026: служебный пункт показывать только при совпадении с введённым текстом; при `red_t` пункта `red_new` нет. Существующие сети идут первыми: точное совпадение, затем совпадения по префиксу; служебный пункт — после них, если соответствует префиксу. Для green правила симметричны.

После вставки класса показывать пустой многострочный объект и меню параметров у каретки. После вставки имени поля показывать `имя: |,` (здесь `|` обозначает каретку, не символ документа), затем меню значений. После завершённого значения — следующая строка того же объекта и меню его оставшихся допустимых полей. Промежуточный неполный текст разрешён. Вложенное значение сначала завершается внутри своей структуры; переход к родительскому полю не должен обрывать путь Signal или вложенный объект.

## Клавиатура — замечания 6–8, 11

Проектное решение: в текстовом редакторе Tab всегда вставляет один символ U+0009, в том числе при открытом меню; значение визуального `tab-size` — 2. Enter или клик принимают подсказку. Уточнение пользователя 21.11.2026: Tab также завершает введённое имя сети; сначала завершить сетевой токен, затем вставить табуляцию в той же транзакции. В поле формы Tab завершает имя и переводит фокус, без вставки табуляции. За пределами textarea обычная навигация Tab сохраняется. Уход из textarea клавиатурой — Shift+Tab. Не добавлять обработку Tab глобально.

Форматирование: Option+Command+L на macOS, Ctrl+Alt+L на Windows/Linux, только при фокусе `#document`. Указание комбинации разместить в существующем `#document-hint`; отдельная кнопка форматирования не нужна. Единый порядок полей используют форматтер, подсказки и шаблоны; исходная отправная точка — `DEVICE_FIELDS` в `src/config-completion.js`. Форматтер не заполняет отсутствующие поля и не удаляет комментарии. Подробные ограничения — задача 0005.
