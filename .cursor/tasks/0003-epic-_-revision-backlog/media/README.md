# Материалы эпика правок (второй раунд)

Артефакты по **группам тем**. Исходные формулировки сохранены; по поручению 21.11.2026 подготовлены дочерние задачи, карта — ниже. Если группа новых замечаний неочевидна — [unsorted/backlog.md](unsorted/backlog.md).

## Группы

| Группа | Каталог | О чём |
|--------|---------|--------|
| Редактор и конфигурация | [editor/](editor/) | Текст, грамматика, подсказки, диагностика, примеры в коде |
| Интерфейс и раскладка | [ui/](ui/) | Экраны, навигация, компоненты, визуал, фокус |

| Прочее / неразобранное | [unsorted/](unsorted/) | Временный ящик до сортировки |

## Правила записи

1. Каждый блок — маркированный список с датой `YYYY-MM-DD` и исходной формулировкой (можно сжать для ясности, смысл не менять).
2. Скриншоты кладутся рядом в каталог группы; в markdown — ссылка `![](имя.png)`.
3. Новую группу заводим только по явному указанию пользователя или когда в `unsorted` накопилось ≥3 связанных пункта — тогда обновить эту таблицу.
4. Сохранять исходные замечания; уточнения добавлять отдельными датированными записями. Задачи и решения не подменяют исходные формулировки.
