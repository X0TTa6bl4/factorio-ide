# Проверка статуса диагностики

Дата: 2026-11-22. Образец `f-logic-dev:1.56.1`, Playwright 1.56.1.

## Что изменилось

На `/` и `pages/configure/` строка `.fl-editor__status` показывает результат проверки текущей revision. Подсказка Tab/Enter и ⌥⌘L / Ctrl+Alt+L из `#document-hint` убрана: тот же текст остаётся в статье «Редактор». Колонка сетей больше не держит постоянную панель «Диагностика».

Одна ошибка с диапазоном пишется как «Строка N: причина. Исправление» и даёт «К месту». Несколько ошибок дают счётчик и «Список». Остановка симуляции без диапазона, например деление на ноль, не получает выдуманный номер строки. Пока поле ещё не совпадает с принятым текстом, статус — «Изменено · требуется проверка», старые подчёркивания не рисуются. Пока запуск или шаг не завершились, при пустой диагностике статус — «Проверка…». Объявление `aria-live="polite"` ждёт паузу ввода и не срабатывает на каждый символ. Фокус остаётся в поле, пока пользователь сам не нажмёт «К месту».

```sh
  test/browser/docs-page.test.mjs
```

27 тестов, без падений.

- Оба адреса редактора: синтаксис, неизвестная сеть `blue_1`, дробное количество и деление на ноль дают действие в статусе. Подчёркивания, список и кнопка запуска совпадают с этим набором.
- 320 px: длинная строка про дробь переносится, документ не шире окна. На 390 px «К месту» с клавиатуры выделяет `blue_1` и оставляет панель кода.
- Несколько ошибок открываются «Списком» с клавиатуры. После исправления статус «Код проверен», старое сообщение и revision не остаются.
- Руководство по якорю `#editor-keys` содержит Tab, Enter, ⌥⌘L и Ctrl+Alt+L.
- Панели, прокрутка номеров, инспектор сетей, руководство и смешанная схема проходят прежние проверки.

Короткий кадр «Проверка…» во время уже идущего запуска отдельным ожиданием не снимался: к следующему опросу страницы шаг успевает завершиться. Состояние задано в `pages/editor-status.js` и выставляется на время `checking`.
