# Повторная приёмка минимизации (п. 15–18)

## Контекст

Второй проход [эпика 0004](../0000-ui-minimization-round.md) после задач 0010–0012. Замечания 15–18 в [media/](../media/README.md).

## Цель

Подтвердить соответствие уточнённым требованиям workbench, меню и gutter; закрыть эпик повторно.

## Границы

### Входит

- Матрица проверки 15–18 + регрессия 1–14 без критических отклонений.
- Сквозной сценарий: три вида на одной странице, меню topbar, gutter на широком экране.
- Отчёт в `media/verification.md`, обновление статуса эпика.

### Не входит

- Новая функциональность вне замечаний; коммит.

|---|---|---|

- Проверить оба адреса редактора из корня и под `/factorio-ide/`, прямой `pages/event/`, а также меню остальных рабочих страниц и руководства. Размеры: 320/390/768/900/901/1440/1920 px, высоты 600/900, масштаб текста 200%, точный и touch указатель, клавиатура.
- Сквозной сценарий: изменить обычную конфигурацию → открыть «События» без навигации → изменить/проверить сценарий → выполнить шаг → проверить источник сигналов в общей таблице → вернуться к коду → undo/redo → ошибка и «К месту» → resize через 900 px → открыть документацию через меню → вернуться → отменить очистку → подтвердить очистку → перезагрузить. Тексты и состояние не теряются до подтверждённой очистки; сохранённые именованные схемы не затрагиваются.
- Обновить проверки, которые закрепляли старую ссылку `#open-events`, отдельную кнопку документации или кнопку нового черновика в шапке; заменить их ожиданиями реального поведения. Не ограничиваться проверкой тегов и классов.
- По риску изменения запустить через существующий Docker-контур тесты конфигурации, событий/Worker lifecycle, сетей, навигации/хранения, раскладки и библиотечных компонентов. Точные команды взять из актуального `dev/` и инструкций запуска при реализации; `test:full` не считать существующим скриптом без проверки конфигурации.
- Сохранить команды, коды выхода, фактическую матрицу, снимки до/после и открытые дефекты в `media/verification.md`. Просмотреть снимки узкого/широкого workbench, меню и gutter вручную. Проверить отсутствие внешнего scroll, обрезания управляющих элементов, дублирующих id и битых ARIA-связей.
- Сопоставить весь набор 1–18 с задачами и результатами. Эпик закрывать только после 0010–0012, фактической повторной приёмки и синхронизации документации; завершённые 0001–0009 сохраняют исторические результаты первой волны.
