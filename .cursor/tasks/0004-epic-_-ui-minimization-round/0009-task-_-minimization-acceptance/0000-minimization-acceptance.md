# Приёмка компактного интерфейса

## Контекст

Замечания 1–14 [эпика 0004](../0000-ui-minimization-round.md). Исходные формулировки сохранены в [media](../media/README.md); решения, аудит библиотеки и матрица проверки — в [проекте UI](../media/ui/design.md).

## Цель

Все 14 замечаний подтверждены реальным прогоном, нет незакрытых критических регрессий.

## Границы

### Входит

- Пройти матрицу `../media/ui/design.md`: каталог, образец, оба адреса редактора, события и остальные экраны симуляции, корневой URL и подкаталог.
- Проверить 320/390/768/900/901/1440/1920 px, высоты 600/900, touch и клавиатуру, resize с открытыми панелями, длинные код/сети/диагностику.
- Подтвердить каждое замечание 1–14 ссылкой на реализующую задачу и результат. Проверить доступность руководства и раздела совместимости после удаления модалки/подсказки.
- Запустить подходящие существующие browser-тесты и проверки затронутого поведения через Docker; сохранить отчёт и снимки в media задачи. Обновить `ui/README.md` и `.cursor/docs/specs/editor.md` по фактическому UI, убрать устаревшие описания инспектора/диагностики/навигации.

### Не входит

- Смена стека, игровая семантика, новый API движка, коммит и публикация.
- Реализация соседних задач; подготовка этой задачи сама по себе не запускает интеграцию.
