# Проверка компактного экрана событий

Дата: 2026-11-22. Образец `f-logic-dev:1.56.1`, Playwright 1.56.1.

## Что изменилось

`pages/event/` больше не держит постоянные колонки настроек и диагностики. Код — основная область. В заголовке рабочей области кнопки «Код» и «Сети»: шире 900 px сети справа, до 900 px видна одна панель, сначала код. «Настройки и подключения» и «Состояние, сообщения и снимок» раскрываются под кодом и сохраняют значения, пока скрыты.

Пульт оставляет слова «Проверить» и «Остановить». «Шаг» и «Сброс» — иконки 40×40. Запуска, паузы, скорости и шага назад нет. Ревизия, прогон, отклик и сведения стенда лежат в настройках. Короткая причина стоит у кода, полный текст открывает «Подробнее».

## Прогон

Команда из корня, код выхода 0.

```sh
docker run --rm --init --ipc=host --user "$(id -u):$(id -g)" \
  -e HOME=/tmp -e F_LOGIC_DEV_PACKAGE=/opt/f-logic-dev/package.json \
  -v "$PWD:/workspace" -w /workspace f-logic-dev:1.56.1 \
  node --test --test-concurrency=1 --test-reporter=spec \
  test/browser/event-page.test.mjs \
  test/browser/screen-layout.test.mjs \
  test/browser/revision-acceptance.test.mjs \
  test/browser/examples.test.mjs \
  test/browser/docs-page.test.mjs
```

Первый проход: 20 из 21. Новый тест ждал текст «разрыв», пока «Выполнять каждый тик» был выключен и `main` не вызывался. После возврата режима тот же файл:

```sh
docker run --rm --init --ipc=host --user "$(id -u):$(id -g)" \
  -e HOME=/tmp -e F_LOGIC_DEV_PACKAGE=/opt/f-logic-dev/package.json \
  -v "$PWD:/workspace" -w /workspace f-logic-dev:1.56.1 \
  node --test --test-concurrency=1 --test-reporter=spec \
  test/browser/event-page.test.mjs
```

10 тестов, код выхода 0.

- Проверка, шаг, сброс, остановка, лимит, зависание и снимок сохраняют прежнее поведение. Неуспешный шаг не меняет номер тика.
- На 390 px код виден, служебных полос под пультом нет. Настройки, сети и полная причина открываются из рабочей области. Скрытые JSON, лимит и флажок не теряют значение. Фокус в сетях при сужении окна оставляет колонку сетей.
- На 1440 px код шире колонки сетей, колонка справа и не уже 16rem. Таблица одна.
- Клавиатура переводит фокус с «Код» на «Сети», Enter скрывает и показывает колонку, контур фокуса виден. Escape закрывает «Подробнее» и диалог снимка; фокус возвращается на кнопку снимка.
- Возврат «Обычные комбинаторы» сохраняет черновик редактора. Arrival по-прежнему публикует signal-A на границе 1.

Страница открыта в браузере на 390×700 и 1440×800. На телефоне код, «Проверить», иконки шага и сброса и «Остановить» помещаются без прокрутки документа. На широком окне проверка доходит до «Готово», шаг публикует тик 1, signal-A и `arrived: true`. Введённый лимит при этом остаётся 1000.
