# Компактный тулбар симуляции и topbar

## Контекст

Замечания 3–5, 13–14 [эпика 0004](../0000-ui-minimization-round.md). Исходные формулировки сохранены в [media](../media/README.md); решения, аудит библиотеки и матрица проверки — в [проекте UI](../media/ui/design.md).

## Цель

Play/pause не меняет габариты, действия имеют имена, недоступные действия отключены.

## Границы

### Входит

- Применить образец `compact-toolbar.html` на рабочих экранах с управлением симуляцией, прежде всего `/`, `pages/configure/`, `pages/debugger/`, `pages/circuit/`; экран событий завершает 0008. Состав действий определять фактическими возможностями, не добавлять неподдержанный шаг назад.
- Сохранить обработчики `#play`, `#step`, `#back`, `#reset`, статусы выполнения и блокировки. Заменить видимый текст SVG-иконками, обеспечить доступные имена/tooltip. Play/pause сохраняет размеры и `aria-pressed`.
- Для скорости убрать внешний лейбл, в кнопке число, в списке тик/с и заголовок «Скорость». Сохранить существующий набор скоростей и поведение таймера.
- Убрать видимое «Текущий тик», сохранить число и доступное имя; сохранить доступные сообщения состояния.
- Убрать дублирующий заголовок «Редактор» из topbar двух адресов редактора, оставить h1 для структуры страницы. Остальные названия экранов без причины не убирать.
- После переноса справки в 0001 не дублировать её в тулбаре. «Новый черновик» — действие документа/схемы, не симуляции; согласовать место с 0001, не возвращать в минимальный пульт.

### Не входит

- Смена стека, игровая семантика, новый API движка, коммит и публикация.
- Реализация соседних задач; подготовка этой задачи сама по себе не запускает интеграцию.

## Зависимости
