# Библиотека компактного интерфейса

## Контекст

Замечания 6; образцы для 2–5, 8–10, 13–14 [эпика 0004](../0000-ui-minimization-round.md). Исходные формулировки сохранены в [media](../media/README.md); решения, аудит библиотеки и матрица проверки — в [проекте UI](../media/ui/design.md).

## Цель

Все элементы библиотеки учтены в ревью; повторяющиеся dropdown используют существующий data-select.

## Границы

### Входит

- Провести ревью всех `ui/components/*.html`; результат и решения по каждому элементу — в `../media/ui/design.md`.
- Расширить существующий `data-select` в `ui/scripts/widgets.js`: необязательный `data-menu-title`, `data-menu-width`, `data-value-only`. Без заголовка не оставлять пустой блок; без новых атрибутов сохранить контракт старых полей, поиск, disabled/error, `.value`, `change` и клавиатуру.
- Создать канонические `ui/components/compact-toolbar.html`, `compact-workbench.html`, `ui/styles/compact.css`, `ui/scripts/compact.js`, собрать `ui/compact.html` и зарегистрировать в `ui/index.html` с раскрываемыми исходниками.
- Показать play/pause фиксированного размера, шаг/назад/сброс, компактную скорость, тик, undo/redo в заголовке, адаптивные панели, диагностику в статусе, настройки события и общий скролл кода/gutter.
- Образцы интерактивны, но не подключают движок, Worker или пользовательский код. Демонстрационный характер указан явно.

### Не входит

- Смена стека, игровая семантика, новый API движка, коммит и публикация.
- Реализация соседних задач; подготовка этой задачи сама по себе не запускает интеграцию.
