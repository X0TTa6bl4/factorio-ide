# Узкая колонка gutter без переноса номеров

## Контекст

Замечание 18 [эпика 0004](../0000-ui-minimization-round.md). [media/editor/notes.md](../media/editor/notes.md). Регрессия или пробел после 0006 на широком stage.

## Воспроизведение

Открыть `/` на широком окне, длинный код в `#code-panel`. `div#gutter` растягивается; номера «01», «02» … отображаются в **две колонки**.

## Цель

Gutter фиксированной минимальной ширины, одна колонка номеров на всех размерах.

## Границы

### Входит

- CSS и при необходимости разметка/скрипт отрисовки номеров в `pages/code-paint.js`, `ui/styles/`, оба адреса редактора, встроенный редактор после 0010.
- Не ломать синхронную прокрутку из 0006.

### Не входит

- Workbench (0010), меню topbar (0012), коммит.

## Зависимости

После 0006; желательно после или параллельно с 0010, если затронут общий редактор.

## Уточнение исправления и приёмки от 23.11.2026

Причина растяжения пока не подтверждена: запись замечания описывает наблюдение пользователя, а не установленный CSS-дефект. Перед исправлением проверить вычисленные grid/flex-свойства `.fl-editor`, gutter и контейнеров после 0010, включая наследование/переопределения в `ui/styles/`. Не фиксировать проблему шириной всего редактора или отключением адаптивности.

- Ширина gutter не зависит от свободной ширины stage; каждый номер занимает отдельную строку, без CSS columns, wrap или распределения по горизонтали. Для номеров с тремя/четырьмя цифрами предусмотреть достаточную ширину без обрезания; рост допустим только по числу цифр, а не по размеру окна.
- У textarea, gutter и слоя подсветки одинаковые вертикальные метрики. Исправление не должно нарушить wheel/touch/программную синхронизацию, горизонтальный scroll кода, выделение и переход к ошибке из 0006/0007.
- Проверить оба адреса редактора, встроенные события и сохранённый отдельный `pages/event/`; исправить соответствующий канонический библиотечный редактор, если причина в общем стиле.

### Дополнительные критерии приёмки

- [x] На 901/1440/1920 px ширина gutter при том же количестве цифр постоянна, номера идут одной вертикальной колонкой; исходный дефект не воспроизводится.
- [x] Файлы 30+, 100+ и 1000+ строк не обрезают номера и не переносят их; на 320/390 px код сохраняет рабочую ширину.
- [x] Прокрутка над номерами, над кодом и переход к ошибке сохраняют соответствие номеров, текста и подчёркиваний.
