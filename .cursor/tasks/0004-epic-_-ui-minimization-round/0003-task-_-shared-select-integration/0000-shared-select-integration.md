# Применение общего выпадающего контроля

## Контекст

Замечания 6 [эпика 0004](../0000-ui-minimization-round.md). Исходные формулировки сохранены в [media](../media/README.md); решения, аудит библиотеки и матрица проверки — в [проекте UI](../media/ui/design.md).

## Цель

Все выпадающие поля используют одно поведение, отсутствующие заголовки не занимают место.

## Границы

### Входит

- Найти все выпадающие поля рабочих страниц и сравнить с аудитом библиотеки. Использовать `data-select` и экспорты `ui/scripts/widgets.js`; отдельную реализацию меню не создавать.
- В `index.html`, `pages/configure/index.html`, `pages/debugger/index.html` и остальных фактически найденных потребителях заменить ручные варианты, где они расходятся с общим контрактом. Сохранить ID, значения, события, placeholder, disabled/error и зависимые поля.
- Опциональный заголовок задавать данными; не создавать пустые заголовки. Поиск сигнала и подсказки у каретки сохраняют свои назначения, не становятся dropdown без поиска.
- Составить перечень перенесённых и уже соответствующих полей в отчёте задачи. Компактный тулбар подключается в 0004, панели — в 0005/0008.

### Не входит

- Смена стека, игровая семантика, новый API движка, коммит и публикация.
- Реализация соседних задач; подготовка этой задачи сама по себе не запускает интеграцию.
