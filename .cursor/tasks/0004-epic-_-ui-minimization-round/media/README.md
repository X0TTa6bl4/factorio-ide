## Правила записи

1. Пункты — маркированный список с датой `YYYY-MM-DD` и номером замечания в эпике.
2. Сохранять DOM Path и id элементов, если указаны пользователем.
3. Уточнения — отдельными датированными записями; исходный смысл не менять.
