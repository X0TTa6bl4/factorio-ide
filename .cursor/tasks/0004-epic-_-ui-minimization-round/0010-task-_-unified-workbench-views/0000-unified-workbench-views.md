# Единая workbench: код, сети и события на одной странице

## Контекст

Уточнения 15–16 и п. 9 [эпика 0004](../0000-ui-minimization-round.md) после приёмки 0005/0009. Записи: [media/ui/notes.md](../media/ui/notes.md), [simulation/notes.md](../media/simulation/notes.md). Образец переключателей — `pages/event/index.html` (`data-work-view`, серый фон, активная кнопка).

## Цель

На `/` и `pages/configure/` «Код», «Сети» и «События» — три одинаковые кнопки в **шапке панели кода** (не отдельный `fl-panel__head` workbench); переключение только меняет содержимое ниже, без `a#open-events`.

## Границы

### Входит

- Перенести `fl-panel__head` (переключатели + undo/redo) **внутрь** `#code-panel` или эквивалентной секции, визуально единой с редактором (п. 15).
- Три кнопки `data-work-view` для code / networks / events; стиль как на странице события; **без** ссылки на `pages/event/` из заголовка (п. 16).
- Режим «События»: событийный редактор и статус на той же странице; таблица сетей **та же**, что в режиме «Сети» (общий DOM или синхронное состояние без дублирования данных).
- Убрать `#new-draft` / «Новый черновик» из шапки панели (перенос в задачу 0012).
- Шире 900 px сохранить раскладку колонок по [design.md](../media/ui/design.md); до 900 px — одна активная панель.
- Сохранить черновик в `sessionStorage`, историю undo, diagnostic scroll, id редакторов. Обновить browser-тесты workbench.

### Не входит

- Выпадающее меню topbar (0012), фикс gutter по ширине (0011), коммит и публикация.
- Полное удаление `pages/event/` (допустимо оставить для сценария/тестов с явной ссылкой «Углублённый сценарий» только если это не противоречит п. 16 — по умолчанию не показывать в шапке).
