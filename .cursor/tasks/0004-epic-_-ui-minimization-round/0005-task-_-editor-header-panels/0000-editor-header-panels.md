# Панели кода, сетей и событий в заголовке

## Контекст

Замечания 2, 9 [эпика 0004](../0000-ui-minimization-round.md). Исходные формулировки сохранены в [media](../media/README.md); решения, аудит библиотеки и матрица проверки — в [проекте UI](../media/ui/design.md).

## Цель

Undo/redo находится в заголовке и сохраняет историю при переключениях.

## Границы

### Входит

- На `/` и `pages/configure/` перенести `#undo`/`#redo` в `.fl-panel__head` кода. Размер 32 px на точном указателе, меньше симуляционных 40 px; на touch сохранить удобную зону. Сохранить историю, хоткеи, disabled и существующий tooltip.
- По `compact-workbench.html` собрать переключатели «Код / Сети / События». Использовать кнопки раскрытия `aria-expanded`/`aria-controls`, не смешивать их с неполной ARIA-моделью tabs.
- Шире 900 px код или события слева, сети отдельной колонкой справа, которую можно скрыть. До 900 px одна активная рабочая панель, начальная — Код. Данные сетей не дублировать вторым DOM-деревом; при resize сохранять состояние документа и не скрывать фокус.
- Сохранить DOM-id textarea, номера строк, слой подсветки, автодополнение, таблицы и диагностические переходы. Переключение не создаёт новый Circuit, revision или прогон.
- Переход к событиям должен вести на существующий `pages/event/index.html` с сохранением текущего черновика по существующему механизму; если общая модель событий внутри редактора отсутствует, использовать прямую ссылку в этой позиции и явно отделить её от локальных раскрываемых панелей. Не обещать единого исполнения обычных и событийных схем.
- Старую отдельную полосу переключателей/опустевшие контейнеры убрать. Документ не прокручивается снаружи; код и сети прокручиваются внутри.

### Не входит

- Смена стека, игровая семантика, новый API движка, коммит и публикация.
- Реализация соседних задач; подготовка этой задачи сама по себе не запускает интеграцию.
