# Проект страницы пользовательского руководства

## Референс и стиль

[Laravel.su — документация](https://laravel.su/docs/13.x/installation), просмотр 22.11.2026: тематическая навигация, оглавление статьи, заголовки с якорями, короткие объяснения с кодом и ссылки на связанные темы. Для f logic применить следующие решения в собственной текущей теме; размеры ниже спроектированы для этого проекта.

## Компоновка

```text
[ƒ. f logic] [Документация]              [В редактор]
[Темы руководства]   [Название статьи]          [На этой странице]
 Начало работы       Короткое назначение       Введение
 Общие понятия       Подзаголовок              Пример
   Сети              Объяснение + пример       Частые ошибки
   Сигналы           Ожидаемый результат
 Комбинаторы         Связанные темы
   Постоянный        [Предыдущая] [Следующая]
   Сравнивающий
 ...
```

- Шапка на основе `.fl-topbar`, закреплена сверху. «В редактор» — обычная локальная ссылка, не сбрасывает черновик. Нет меню «Ещё», кнопки модалки «Совместимость» и входа в UI-каталог. Совместимость — статья в тематической навигации по требованию эпика 0004.
- При ширине от 1200 px три колонки: слева 240 px, статья `minmax(0, 76ch)`, справа 208 px; промежутки 32 px, внешние отступы 24 px, каркас по центру. Боковые панели sticky ниже шапки, со своей прокруткой при переполнении; статья прокручивается с документом. Якоря учитывают высоту шапки.
- При 900–1199 px оставить слева 220 px и статью; «На этой странице» переносится в сворачиваемый блок перед текстом статьи. При ширине менее 900 px одна колонка; перед заголовком кнопка «Разделы», под заголовком сворачиваемое оглавление. Текст и код доступны без открывания меню.
- «Разделы» открывает боковую панель слева шириной `min(320px, 90vw)` поверх страницы с фоном-затемнением, заголовком и явной кнопкой закрытия. Escape/клик по фону закрывают; фокус ограничен открытой панелью и возвращается на кнопку. Выбор статьи закрывает панель и переводит фокус к заголовку статьи. Не показывать desktop и mobile меню одновременно для скринридера.
- В дереве группы раскрываются кнопками с `aria-expanded`, статьи — ссылками; активная статья `aria-current="page"`, выделение существующим янтарным акцентом. В оглавлении только заголовки текущей статьи H2/H3; текущий подраздел `aria-current="location"`. Якорные ссылки доступны с клавиатуры; область статьи — `main`, панели — именованные `nav`.
- Не вводить сторонние шрифты/иконки. Использовать действующие токены поверхностей, текста, границ, радиусов и интервалов. Обычный текст 16 px с межстрочным интервалом около 1.6, код моноширинный, допустим скролл внутри блока кода; не уменьшать весь текст ради длинных строк.

## Статья и взаимодействия

1. H1 и кратко «для чего / когда использовать».
2. Что нужно заранее: ссылки на общие главы и данные примера.
3. Пошаговые действия с реальными названиями элементов приложения.
4. Минимальный рабочий код и текстовый ожидаемый результат с количеством шагов.
5. Ошибки/ограничения и ссылки на основной раздел соответствующего понятия.
6. «См. также», предыдущая/следующая статья.

У блока кода — название языка и кнопка «Копировать»: в буфер попадает только код; успех объявляется коротким доступным сообщением. Ошибка буфера показывается текстом с предложением выделить код вручную. Код не исполняется автоматически и не заменяет текущий черновик. Для перехода из статьи используются обычные ссылки на существующие страницы.

Дерево/оглавление используют стабильные slug из реестра. Переход меняет hash, прямое открытие и перезагрузка сохраняют статью/подраздел. Неизвестный slug — сообщение «Раздел не найден» и переход к началу. Чтение и переключение статей не вызывают API редактора/симулятора.

## Принцип единого определения

В статье «Сети» определены создание, подключения, цвета и суммирование. В Decider: «Подключите вход к `red_1`, выход к `red_2`», ссылка «Подключение к сетям» на `#networks-ports`; отдельный пример копирования количества. Пояснение петли ссылается на `#simulation-feedback`. Повторять всю главу сетей у каждого устройства не нужно. То же правило применяется к сигналам, маскам, операндам и тикам.

## Библиотека

Руководство не является каталогом компонентов. Публичных разделов «библиотека», «исходник элемента», каталогов HTML и требований к пользователю изучать `ui/` нет. По уточнению пользователя новые элементы разработаны в UI-библиотеке. Отсутствие UI-каталога внутри публичного руководства не отменяет обязательного ведения библиотеки.


## Исполняемые образцы и вставки

Канонический результат — [ui/docs.html](../../../../ui/docs.html), отдельный полноразмерный образец. В [каталоге](../../../../ui/index.html#documentation) зарегистрированы фрагменты с раскрываемым HTML.

| Элемент | Конкретный исходник |
|---|---|
| Дерево разделов, мобильная панель | [docs-navigation.html](../../../../ui/components/docs-navigation.html) |
| Статья, код/копирование, примечание/ошибка/результат, ссылки | [docs-article.html](../../../../ui/components/docs-article.html) |
| Оглавление статьи | [docs-outline.html](../../../../ui/components/docs-outline.html) |
| Типографика, цвета из токенов, responsive и состояния | [docs.css](../../../../ui/styles/docs.css) |
| Переходы, копирование, dialog и фокус | [docs.js](../../../../ui/scripts/docs.js) |

Подключение в будущей рабочей странице:

```html
<link rel="stylesheet" href="../../ui/styles/tokens.css">
<link rel="stylesheet" href="../../ui/styles/components.css">
<link rel="stylesheet" href="../../ui/styles/layout.css">
<link rel="stylesheet" href="../../ui/styles/docs.css">
<div class="fl-docs" data-docs>
  <div class="fl-docs__layout">
    <aside class="fl-docs__side fl-docs__nav"><!-- docs-navigation.html --></aside>
    <main class="fl-docs__content"><!-- docs-article.html --></main>
    <aside class="fl-docs__side fl-docs__toc"><!-- docs-outline.html --></aside>
  </div>
</div>
```

```js
import { mountDocumentation } from "../../ui/scripts/docs.js";
// После вставки канонических HTML-фрагментов:
mountDocumentation(document.querySelector("[data-docs]"));
```

Точные значения и состояния заданы CSS, а не требуют интерпретации словесного описания:

```css
.fl-docs__layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 76ch) 208px;
  gap: 32px;
  padding: 40px 28px 72px;
}
.fl-docs__tree a[aria-current], .fl-docs__outline a[aria-current] {
  border-color: var(--fl-accent);
  color: var(--fl-accent);
  background: var(--fl-raised);
}
```

Полные media queries, размеры шрифтов, отступы блоков, ошибки, результаты, код и мобильный dialog находятся в каноническом CSS; сокращённые вставки выше показывают контракт, не заменяют полный файл. `pages/docs/docs.css` и `page.js` при реализации должны подключать общие стили/поведение библиотеки, а не расходиться с ними.
