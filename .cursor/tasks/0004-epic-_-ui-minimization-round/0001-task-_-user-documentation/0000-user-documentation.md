# Пользовательское руководство и кнопка «Документация»

## Контекст

Замечание №14 от 22.11.2026: удалить «Ещё», добавить «Документация»; разработать руководство пользователя с принципами оформления Laravel.su, сохранив текущий стиль f logic. Общие элементы и взаимодействие описывать отдельными статьями, из описаний комбинаторов давать ссылки на них. Библиотека элементов в руководстве не нужна.

Сейчас `<details class="fl-more">` присутствует на восьми рабочих HTML-страницах; отдельной страницы руководства в `pages/` нет. Меню содержит ссылки на вторичные страницы и действие «Новый черновик» в редакторе. Внутренние `.cursor/docs/specs/` описывают модель и API, `ui/` — разработку интерфейса; они не заменяют пользовательское руководство.

Исследованный референс: [документация Laravel.su — установка](https://laravel.su/docs/13.x/installation), 22.11.2026. Наблюдаемые принципы: тематические группы разделов, оглавление статьи «На этой странице», якоря, объяснение перед примером, связанные темы. Компоновка, адаптивность и точные размеры для f logic спроектированы в [design.md](design.md); это проектное решение, а не требование копировать Laravel.

## Цель

Пользователь открывает руководство из любой рабочей страницы, самостоятельно создаёт первую схему и запускает симуляцию; находит общие правила и описание каждого доступного устройства через боковую навигацию и перекрёстные ссылки.

## Карта содержания

| Группа | Статьи и обязательное содержание |
|---|---|
| Начало работы | Что делает приложение и его границы; первая рабочая схема Constant → Decider на двух сетях; как вставить код, запустить, сделать шаг, увидеть результат и сбросить |
| Редактор | Ввод кода, подсказки, создание имён сетей, Tab/Enter/Esc, форматирование и хоткеи по ОС, undo/redo, подчёркивание ошибок и переход «К месту» |
| Общие понятия | Сети (`networks`): создание/имена/подключения/цвета/суммирование и чтение; сигналы (`signals`): каталог, количества и метасигналы; операнды и условия (`operands`): константа/сигнал, маски, логические связки; симуляция (`simulation`): тики, запуск/пауза/шаг/назад/сброс, начальное состояние и обратная связь |
| Комбинаторы | Отдельные статьи Constant, Arithmetic, Decider, Selector: назначение, параметры, действия, рабочий пример, ожидаемый результат, ошибки и ссылки на общие понятия |
| Другие устройства | Лампа, хранилище, станции/поезда — текущее доступное поведение и явные ограничения; событийный комбинатор — редактор события, запуск, диагностика и пример |
| Работа со схемой | Сохранение/импорт/экспорт, открытие примеров, просмотр сетей и отладчик; реальные страницы и действия, без обещаний несуществующего общего состояния между экранами |
| Решение проблем | Не запускается симуляция, неизвестное имя/сигнал, неполный выход Decider, нет выходного сигнала, рост количества при обратной связи; от симптома к исправлению и ссылке на основной раздел |

Карта перечисляет требуемое покрытие, не разрешает описывать отсутствующее поведение. Перед реализацией сверить фактические возможности каждого экрана и соответствующим образом обозначить ограничения.
