# Навигация по проекту

Работай в текущем `f logic`. Не используй пути и карты сервисов из исходного `kmut-ml`.

1. Прочитай корневой `AGENTS.md` и инструкции в целевой директории.
2. Посмотри верхний уровень и манифесты через `rg --files --hidden`, исключая `.git`, зависимости и результаты сборки. Не обходи соседние проекты.
3. Установи реальные точки входа, модули, тесты и команды из конфигурации. Если кода ещё нет, так и сообщи.
4. Для симулятора разделяй описание схемы, состояние выполнения, движок тиков, язык и интерфейс. Названия будущих директорий — предложение, пока их нет на диске.
5. Когда нужен специальный workflow, открой [skills.md](skills.md). Не загружай все скиллы заранее.
6. Git-корень определяй через `git rev-parse --show-toplevel`; отсутствие репозитория допустимо.

Результат: найдены фактические файлы и границы изменения, либо явно зафиксировано, что проект ещё не создан.
