# Выбор workflow

| Задача | Скилл |
|---|---|
| Снимок окружения и ветки | `workspace-preflight-ru` |
| Описать задачу, эпик, баг, исправления ревью | `task-workflow-ru` |
| Выполнить описанную задачу | `work-orchestrator-ru` |
| Разделить модель, сценарий и адаптеры | `layered-modules-architecture-ru` |
| Исправить конкретный провал CI или теста | `ci-failure-fix` |
| Структурное ревью | `thermo-nuclear-code-quality-review` |
| Документация модуля и контрактов | `module-contract-docs-ru` |
| Пользовательская wiki | `wiki-module-docs-ru` |
| Спецификация и текст PR/MR | `task-sdd-handoff-ru` |
| Коммит, ветка, merge, pull, push | `git-commit-ru` |
| Создать или обновить скилл / правило | `command-skill-authoring` |

Тесты, линтер и сборка выбираются из реальной конфигурации проекта. Эти скиллы не требуют PHP, Docker, Jira, Spec Kit или конкретной модели агента.
