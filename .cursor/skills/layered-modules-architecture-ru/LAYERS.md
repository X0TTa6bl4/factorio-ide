# Ответственность частей

| Часть | Владеет | Не должна знать |
|---|---|---|
| Модель схемы | ID, настройки устройств, топология | DOM и формат виджетов |
| Движок | тик, сигналы, runtime-состояние | UI, редактор кода, browser storage |
| Язык | текст, диагностика, преобразование в схему | управление кадрами UI |
| UI | события ввода, выбор, представление | скрытая вторая реализация семантики тика |
| Хранение | формат проекта, миграция формата | вычисление комбинаторов |

Сценарии `step`, `reset`, `restore` должны работать без интерфейса. Не требуй классов `Service`, DTO или repository, если достаточно функций и структур данных. Согласованные соглашения существующего кода имеют приоритет.
