# Поток данных

```text
текст / визуальное редактирование → описание схемы
описание схемы + состояние + входные события → шаг движка → новое состояние
новое состояние → представление UI / снимок истории
```

При изменении тика обозначь фазу чтения и фазу записи. Все вычислители читают опубликованное состояние; запись не должна менять данные, которые ещё читают другие устройства. Суммируй вклады источников и публикуй результат согласованно.

Правила разных устройств, начального состояния и задержек проверяются отдельно для целевой версии Factorio. Учитывай внутреннее состояние и источник случайности там, где они реально нужны. Воспроизводимый откат требует снимка этих данных.

Не привязывай один тик симуляции к одному кадру отрисовки. Скорость проигрывания управляет числом шагов; семантика одного шага остаётся той же. Проверяй эту часть тестами без DOM.
