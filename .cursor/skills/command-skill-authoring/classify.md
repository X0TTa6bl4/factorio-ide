# Правило или скилл

Постоянная короткая норма (язык, границы, совместимость) — правило. В Cursor для неё подходит `.mdc` с `alwaysApply` или `globs`; существенное общее правило продублируй по смыслу в `AGENTS.md`, который читает Codex.

Условная процедура с результатом, шагами, шаблоном или скриптом — скилл с точным описанием, когда он нужен. Не превращай все профессиональные знания в обязательные правила.

Если файл смешивает постоянную норму и большой runbook, раздели их без дублирования. Не меняй общую конфигурацию клиента ради одного project skill.
