# Новый скилл

1. Определи задачи, которые он обслуживает, и случаи, когда не нужен.
2. Создай `.cursor/skills/<kebab-name>/SKILL.md` с YAML `name`, `description` и полезными инструкциями. Имя папки и `name` совпадают.
3. Добавь лишь реально необходимые шаблоны, ссылки и скрипты. Описание в YAML должно помогать выбору workflow.
4. Для действия с последствиями учитывай уже данное поручение; не создавай повторные подтверждения ради процесса.
5. Проверь frontmatter, относительные ссылки, отсутствие секретов и работоспособность нового кода.
6. Добавь строку в `repo-orientation-ru/skills.md`, если workflow нужен в карте проекта.
