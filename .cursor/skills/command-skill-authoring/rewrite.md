# Обновление скилла

Прочитай существующий entrypoint и только затронутые зависимости. Установи конкретную проблему: ложный триггер, неподдержанный инструмент, лишнее ограничение, отсутствующая ссылка или неправильная последовательность.

Сделай минимальную правку, которая устраняет проблему. Сохрани имена и пользовательские соглашения, если не поручено изменить их. При переименовании обнови реальные входящие ссылки. Не переписывай архивы и соседние скиллы для единообразия.

Проверь структуру, ссылки и сценарий, в котором проявлялась ошибка. Новые скрипты испытай на безопасных временных данных. Не добавляй обязательные проверки или согласования из гипотетической осторожности.
