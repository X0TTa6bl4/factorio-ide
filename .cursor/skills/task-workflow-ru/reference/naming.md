# Имена и размещение

Директория: `NNNN-{epic|task|bug}-{jira|_}-{slug}/`, slug — короткий kebab-case.

Верхний номер выдавай по максимуму среди прямых детей `.cursor/tasks/`, прямых детей `_archive/` (если есть) и `.task-sequence`, плюс один. После создания обнови `.task-sequence`. Не сканируй все вложенные эпики для этого номера.

Внутри эпика задачи и баги имеют собственную серию `0001+`; глобальный счётчик не меняется.

```text
0001-epic-_-simulator/
  0000-simulator.md
  0001-task-_-tick-engine/
    0000-tick-engine.md
    0100-model.md
    0200-step.md
    0201-fix-feedback.md
    media/
```

Эпик содержит директории задач. Шаги внутри задачи — файлы `0100`, `0200`; fix-up к `0200` — `0201`–`0299`. Новый основной шаг после них — `0300`. Корневой файл — `0000-<slug>.md`.

Frontmatter: `type`, `status`, `priority`, `created`, `updated`, при необходимости `parent` и `predecessor`. Используй шаблон, не дублируй номер задачи и Jira в дополнительных ID. Старые номера не переиспользуй. Исторические архивы не переименовывай.
