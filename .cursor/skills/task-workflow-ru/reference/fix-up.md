# Исправления после ревью

У локального исправления укажи исходный шаг в `predecessor`, замечание, ожидаемое поведение и проверку. Номер `NNnn` относится к `NN00`: `0201` — первый fix-up шага `0200`.

Для большой самостоятельной волны исправлений создай соседнюю задачу со ссылкой на исходную; не открывай заново выполненные пункты без причины. Группируй по причине и границе изменения. Не превращай любое замечание оформления в отдельный шаг.

Действительное исправление подтверждается проверкой поведения и обновлением состояния замечания.
