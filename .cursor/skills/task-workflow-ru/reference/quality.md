# Готовность задачи

- Цель и критерии приёмки проверяемы.
- Указаны фактические файлы или явно обозначены будущие компоненты.
- Границы не расширены соседней работой.
- Скиллы и команды доступны в текущем проекте.
- Для завершённой задачи есть фактические результаты нужных проверок.
- Если проверка недоступна, указана причина; результат не представлен как зелёный.
- Не осталось пустых ситуационных секций, фиктивных Jira ID и скопированных фактов другого продукта.
- Требуемая спецификация / PR-черновик завершены; коммит и push выполняются лишь в порученном объёме.
