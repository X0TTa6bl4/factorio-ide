# Контракты модуля

1. Найди модуль через `repo-orientation-ru`; установи существующие публичные точки входа.
2. Прочитай [TEMPLATE.md](TEMPLATE.md). Для браузерного модуля адаптируй HTTP-раздел к экспортируемым функциям, событиям и структурам данных. Не добавляй HTTP или базу данных, если их нет.
3. Опиши входы, выходы, инварианты, ошибки и побочные эффекты. Для движка укажи изменение состояния и момент публикации тика.
4. Подтверждай факты кодом и тестами. Предложения отмечай как предложения; непроверенное — как непроверенное.
5. Сохрани по-русски в `.cursor/docs/modules/<ModuleName>.md`, если пользователь не указал другое место.

Не копируй примеры шаблона как реальные факты. Не оставляй пустые и неприменимые разделы. Не включай секреты. Результат — путь к документу и существенные непроверенные положения.
