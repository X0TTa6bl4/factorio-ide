# Git текущего проекта

Определи фактический Git-корень. `.cursor` здесь не отдельный репозиторий истории.

| Действие | Инструкция |
|---|---|
| Коммит | [commit.md](commit.md) |
| Создание или смена ветки | [branch.md](branch.md) |
| Pull / merge | [pull.md](pull.md) |
| Push | [push.md](push.md) |

Читай только нужную инструкцию. Сохраняй чужие изменения и добавляй в индекс конкретные файлы задачи. Не коммить секреты и результаты локального окружения. Не переписывай историю и не делай force push без явного запроса.

Поручение на коммит позволяет подготовить сообщение и сделать коммит без повторного согласования текста, если пользователь не просил предварительный просмотр. Push требует запроса на публикацию; не следует из запроса на коммит.
