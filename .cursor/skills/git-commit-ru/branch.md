# Ветка

Определи текущую ветку, локальные изменения и требуемую базу. Не считай `origin/dev` существующей или обязательной.

Имя и базу бери из запроса и соглашений проекта. Создавай ветку от установленной базы с `git switch -c <name> --no-track <base>`, если не требуется намеренное отслеживание удалённой ветки. Для существующей ветки используй `git switch <name>`.

Не теряй изменения; не делай автоматический stash или reset. Если работа конфликтует со сменой ветки, выбери изолированный путь или уточни безопасный вариант. Проверь текущую ветку после операции.
