### Endpoint

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/spa/...` | Получить список |
| `GET` | `/spa/.../{id}` | Получить одну запись |
| `POST` | `/spa/...` | Создать запись |
| `PATCH` | `/spa/.../{id}` | Обновить запись |
| `DELETE` | `/spa/.../{id}` | Удалить запись |

### Query-параметры

| Параметр | Тип | Обязательный | Описание |

| `filter` | `json` | Нет | Фильтрация |
| `sort` | `json` | Нет | Сортировка |

## Фильтрация, сортировка, пагинация

### Фильтрация

| Поле | Условия | Описание |
|------|---------|----------|
| `id` | `eq`, `in` | Фильтр по идентификатору |
| `name` | `eq`, `like` | Фильтр по названию |
| `created_at` | `between`, `gte`, `lte` | Фильтр по дате |

Пример:

```
GET /api/entities?filter={"name":{"like":"test"}}
```

### Сортировка

| Поле | Описание |
|------|----------|
| `id` | Сортировка по идентификатору |
| `name` | Сортировка по названию |
| `created_at` | Сортировка по дате создания |

Пример:

```

```
