# Черновик PR/MR

Опиши конечное изменение для ревьюера, не читавшего чат:

1. Проблема и конкретное поведение после изменения.
2. Существенные решения и границы, если они нужны для ревью.
3. Реально выполненные проверки и их исходы.
4. Значимые оставшиеся ограничения.

При наличии шаблона репозитория используй его. Не включай историю обсуждения, отвергнутые варианты, секреты и неподтверждённые «всё зелёное». Для небольшой правки достаточно нескольких предложений и проверки.

При обновлении перепиши описание под итоговый diff. Назови путь локального черновика; удалённое создание PR/MR выполняется только при поручении публикации.
