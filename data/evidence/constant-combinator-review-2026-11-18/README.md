## Применение

[review.json](review.json) — явный вход генератора через `--chooser-review`. Содержит профиль, версию, источник, SHA-256 исходной строки и точное множество ключей каждой вкладки. Команда `./dev/f-logic catalog` использует эту сверку. Без флага генератор работает только по сырым данным; это другой режим, не итог принятой пользовательской правки.

Проверки сверяют SHA строки, распаковку, десять вкладок, все 693 type/name, уникальность и точное равенство экспортированных ordinary-ключей по разделам. Необычные роли, неподходящая версия, потерянные вкладки, дубли или неизвестный ID отвергаются. Base не изменён; метасигналы и wildcard качества сохраняются отдельно от ordinary-набора. В Space Age всего 697 публичных путей: 693 ordinary, три метасигнала и один селектор качества.

Уровень свидетельства — `user-reviewed-blueprint`. Исправленный набор применён как рабочая пользовательская сверка. Сама строка не является записью обхода всех экранов/фильтров GUI; menuConfirmed автоматически не выставляется. Режимы других качеств и клиентская локализация этим файлом не проверялись. Возвращаться к уже разрешённым пяти коллизиям или повторно просить тот же чертёж не требуется.

Фактическая проверка: Docker-команды `./dev/f-logic catalog` и `./dev/f-logic test` (на этом хосте с `DOCKER_DEFAULT_PLATFORM=linux/arm64`) завершились с кодом 0; 54/54 тестов. CLI повторно создаёт те же производные файлы.
