# Каталоги сигналов Factorio 2.1.24

Два независимых снимка из официальной stable-сборки, проверенной 09.11.2026:

- `base/` — core + base, без сторонних модов и DLC.
- `space-age/` — полный профиль core + base + elevated-rails + quality + recycler + space-age. Это полный набор, а не только добавления DLC.

| Файл в каждом профиле | Содержимое |
|---|---|
| `items.json` | Предметы всех подтипов, включая инструменты, модули, оружие и оборудование |
| `fluids.json` | Жидкости и газы |
| `virtual-signals.json` | Виртуальные сигналы, включая специальные записи |
| `entities.json` | Прототипы сущностей |
| `recipes.json` | Рецепты, включая автоматически создаваемые |
| `space-locations.json` | Космические местоположения |
| `asteroid-chunks.json` | Астероидные фрагменты |
| `qualities.json` | Качества как отдельные прототипы |
| `groups.json` | Группы и подгруппы, порядок в данных |

`special-signals.json` выделяет три логических метасигнала и указатель любого качества. Параметры чертежей находятся в профильных файлах с ролью `blueprint-parameter`. `manifest.json` содержит версии, состав профилей, количества, SHA-256 исходного архива и скриптов, добавленные и удалённые Space Age ID и состояние графических файлов.

## Формат записи

`id = type/name`; одинаковое имя предмета, рецепта и сущности не объединяется. `label` содержит подписи en/ru, `labelSource` — способ их получения; неразрешённое название явно помечено и заменено ID/доступной подписью. `role`, `hidden`, `parameter` отделяют обычные записи от метасигналов, параметров и служебных прототипов. `icon.layers` сохраняет игровые пути, размер, смещения, масштаб и оттенок каждого слоя. `localised_name`, когда задан, сохраняется для будущего штатного разрешения локализации.

В каталоге намеренно оставлены скрытые и технические прототипы: 1218 записей base и 2249 Space Age. Это **не количество кнопок игрового меню сигналов**. В частности, скрытые рецепты, параметры чертежей и автоматические правила скрытия одинаковых иконок нельзя считать обычными доступными сигналами. `hide_from_signal_gui`, если явно задан, сохранён; вычисленные C++-движком значения по умолчанию и точный состав меню не подтверждены запуском игры.

## Иконки

Получено 770 уникальных исходных путей к PNG и их слои. Самих PNG в бесплатной headless-сборке нет; `manifest.iconFiles.copied = 0`. Ссылки `__base__/…` — адреса в дистрибутиве игры, не готовые веб-URL. Если запускать сборщик по данным полной установки с графикой, существующие PNG копируются в `icons/<pack>/…`; отсутствующие перечисляются в manifest. Отрисовка многослойных иконок отдельно не выполнялась.

## Обновление

Сначала проверить [stable-релиз](https://factorio.com/api/latest-releases), затем использовать data соответствующей официальной версии. Из корня проекта:

```bash
python3 tools/factorio-catalog/build.py --data-root /путь/к/factorio/data --output /новый/каталог --lua lua --archive /путь/к/официальному-архиву.tar.xz
```

Нужны Python 3.9+ и Lua 5.4. Сборщик не использует Docker, не запускает игровой сервер и не скачивает данные. Он выполняет Lua data stages официальных пакетов с детерминированным обходом таблиц; это не полная эмуляция C++-валидации Factorio. Загружать только доверенные официальные данные. Существующий результат не перезаписывается. Две независимые сборки текущего снимка совпали побайтно.

Для браузера загружать только нужный профиль и категории, а не оба каталога целиком. Производная таблица имён Signal лежит отдельно в `data/signal-catalog/2.1.24` и эти сырые файлы не заменяет.

Источники: [официальная сборка](https://factorio.com/get-download/2.1.24/headless/linux64), [публичные исходники данных Wube](https://github.com/wube/factorio-data), [типы SignalID](https://lua-api.factorio.com/latest/concepts/SignalIDType.html), [скрытие рецептов](https://lua-api.factorio.com/latest/prototypes/RecipePrototype.html#hide_from_signal_gui).
