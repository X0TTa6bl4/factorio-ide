# Чертёж для ручной сверки Space Age

Готовая строка импорта — [blueprint.txt](blueprint.txt). Скопировать содержимое файла целиком в «Импорт строки» Factorio. В чертеже **один постоянный комбинатор**, **10 именованных групп**, **873 сигнала**. Одна группа соответствует одной вкладке пользовательских скриншотов; подгруппы вкладок отдельно не разбиты. Значение каждого сигнала — 1, качество normal.

## Как вернуть результат

1. Импортировать, поставить комбинатор и открыть его.
2. Сравнить каждую группу с соответствующей вкладкой меню. Добавить недостающие сигналы в эту же группу; одинаковое значение 1 достаточно.
3. Если сигнал из черновика отсутствует в меню и оказался лишним, удалить его из группы. Особенно это важно для «Окружения»: там сохранён весь текущий кандидатный набор, включая спорные записи.
4. Сохранить десять групп и экспортировать обновлённый чертёж одного этого комбинатора. Прислать строку экспорта — по ней будут определены добавленные и удалённые type/name.

Импорт доступного через API сигнала не доказывает его наличие в меню. Черновик специально не помечен подтверждённым набором. Метасигналы Each/Everything/Anything и wildcard качества не включены как обычные передаваемые сигналы постоянного комбинатора. Разные типы с одинаковым name не слиты; четыре куска — item, операции обработки — отдельные recipe.

## Проверка и происхождение

Источник — текущий `data/signal-catalog/2.1.24/space-age.json`, только экспортированные ordinary-строки. Хеш источника и количество каждой группы — [manifest.json](manifest.json), читаемый JSON чертежа — [blueprint.json](blueprint.json). Генератор — `tools/signal-catalog/survey-blueprint.mjs`, запускается через Docker.

Чертёж реально импортирован и повторно экспортирован headless Factorio 2.1.24 build 87808 с полным Space Age. [validation.json](validation.json): один комбинатор, десять именованных групп, все 873 игровых ключа и значения сохранены. Проверка — импорт/экспорт предмета blueprint, не проверка всего графического chooser или установки на карту. menuConfirmed остаётся false.

Сверка меню base без Space Age отложена пользователем 18.11.2026 и не требуется для этого чертежа. Уже собранные base-данные сохранены.
