# Библиотека интерфейса f logic

Адаптивные HTML-элементы для будущих страниц. Дизайн: тёмные поверхности, янтарное основное действие, красные/зелёные подключения с текстовыми метками. Системные шрифты, собственные простые SVG, без внешних ресурсов, фреймворка и сборки.

Это технический каталог интерфейса. Пользовательская справка по работе в приложении — [руководство](../pages/docs/index.html); каталог её не заменяет и в текст руководства не входит.

## Где смотреть

- [Рабочее пространство](workspace.html) — пример сборки тех же элементов в страницу.

- [Сценарий события](../pages/event/index.html) — отдельная рабочая страница: код, раскрываемые настройки и состояние, сети колонкой на широком окне и панелью на узком. Проверка, шаг, остановка, лимит и диалог снимка подключены к Worker. Общего прогона с редактором нет.
- [Отладчик](../pages/debugger/index.html) — запуск, пауза, скорость, шаг и сброс одного `step()`; агрегат сети и собственный выход устройства.
- [Сети](../pages/networks/index.html) — создание, подключение, переименование и удаление сетей через общий Circuit.
- [Редактор](../index.html) — код обычных комбинаторов, запуск до паузы и сигналы сетей. [Конфигурация](../pages/configure/index.html) открывает тот же экран.
- [Схема](../pages/project/index.html) — локальное сохранение, импорт и экспорт файла определения.
- [Примеры](../pages/examples/index.html) — схемы четырёх устройств и сценарий Arrival, связанные с движком. Каталог и `workspace.html` остаются макетом.

Это библиотека и демонстрация оформления. Каталог и пример страницы не подключены к движку. Рабочие страницы — [редактор](../index.html), [первый контур](../pages/circuit/index.html), [сценарий события](../pages/event/index.html), [отладчик](../pages/debugger/index.html), [сети](../pages/networks/index.html), [конфигурация](../pages/configure/index.html), [примеры](../pages/examples/index.html) и [схема](../pages/project/index.html). Шкала тиков на странице отладчика восстанавливает сохранённую границу. Примеры сигналов в каталоге статические; редактор каталога — обычный textarea.

## Расположение

```text
ui/
  components/          # Канонические HTML-фрагменты
  styles/tokens.css    # Цвета, шрифты, отступы
  styles/components.css # Базовые и составные элементы
  styles/layout.css    # Каркасы страниц и адаптивные сетки
  scripts/catalog.js   # Компоновка каталога и демонстрационное поведение
  index.html           # Каталог
  workspace.html       # Пример страницы
  tests/               # Отдельный Docker-контур проверки UI
```

## Использование на страницах

Подключить `styles/tokens.css`, затем `styles/components.css` и при необходимости `styles/layout.css`. Вставить нужный HTML из `components/` в документ, затем связать элементы с общей моделью приложения. Библиотека использует префикс `fl-`; новые элементы и их состояния добавлять сюда, чтобы страницы не расходились.

```html
<link rel="stylesheet" href="./ui/styles/tokens.css">
<link rel="stylesheet" href="./ui/styles/components.css">
<link rel="stylesheet" href="./ui/styles/layout.css">

<button class="fl-button fl-button--primary" type="button">
  Создать схему
</button>

<label class="fl-field">
  Название
  <input class="fl-input" type="text" value="Моя схема">
</label>
```

Каталог и пример используют маленький загрузчик доверенных локальных фрагментов:

```html
<div data-ui="device-card"></div>
<script type="module" src="./ui/scripts/catalog.js"></script>
```

Путь `src` зависит от расположения страницы; загрузчик вычисляет URL фрагментов относительно собственного модуля. `data-show-source` добавляет раскрываемый HTML-исходник. Загрузка требует HTTP. Это удобство демонстрации, не обязательный механизм приложения: HTML можно включать непосредственно в страницу. В продуктивных страницах подключать `scripts/widgets.js` и собственные контроллеры модели. `catalog.js` только собирает каталог. Нативный файловый диалог импорта не заменяется выбором.

Загрузчик назначает уникальные ID каждому экземпляру и обновляет `for`/ARIA-ссылки. При ручном копировании нескольких экземпляров это обязанность страницы. `innerHTML` используется только для файлов библиотеки: конфигурацию пользователя и данные схемы выводить через безопасные DOM-методы. Новые диалоги должны иметь собственную связь с открывающей кнопкой; демонстрационный загрузчик рассчитан на один диалог примера.

## Адаптивность и доступность

- Каркас библиотеки: боковая навигация на широком экране, переносимая навигация сверху до 720 px.
- Рабочее пространство и рабочие экраны занимают остаток окна. Документ снаружи не прокручивается. Код, таблицы и длинные панели прокручиваются внутри. До 900 px вторичные колонки закрыты и открываются кнопками, код и команды остаются на экране. Каталог: боковая навигация и колонка разделов прокручиваются отдельно, исходники — в своём блоке.
- Обычные сетки складываются в одну колонку до 1000 px. Элементы не требуют фиксированной ширины контейнера.
- Таблицы, код и шкала тиков при нехватке места прокручиваются внутри своей области, а не растягивают страницу.
- Состояния различаются текстом/рамкой/значком. Цвет не является единственным признаком.
- Видимый фокус, подписи полей, порядок Tab; вкладки поддерживают стрелки, Home/End, диалог — Escape и возврат фокуса.
- Выбор — кнопка и список `data-select`. Стрелки, Home, End, Enter и Escape управляют списком, Tab уходит к следующему элементу, клик снаружи закрывает меню. `data-search="true"` на разметке без готовой кнопки создаёт фильтр; без атрибута поля поиска нет. `data-menu-title` рисует заголовок внутри меню, пустое или отсутствующее значение не занимает место. Смена значения шлёт `change` на скрытом поле. Ошибка — `aria-invalid` на кнопке и связанный текст. Меню подсказок у каретки и поиск имени сети этим списком не заменяются.
- Панель сворачивается кнопкой заголовка. Если фокус был в содержимом, он переходит на эту кнопку.
- Меню подсказок — список у кнопки или у поля (`Ctrl`/`⌘`+`Space`, `Alt`+`↓`). Оно в верхнем слое, прокручивается внутри и не растягивает документ. Состав подсказок задаёт страница; образец показывает подпись без уже набранного префикса. У операции вторичная подпись — знак из каталога (`>`, `+`, `AND`); у режимов Selector знака нет. После класса виден каркас `Arithmetic({ … })` и список параметров; после имени поля — значения пустого поля.
- Подсказка кнопки появляется при наведении и при фокусе с клавиатуры, скрывается по уходу указателя, потере фокуса и Escape. У неё `role="tooltip"`, она связана через `aria-describedby`, не получает фокус и не выходит за окно. Текст действия и сочетание клавиш задаёт страница. Отключённая кнопка сохраняет имя; описание читается наведением на обёртку.
- На `/` и `pages/configure/` колонка содержит только сети: шире 900 px они справа и скрываются кнопкой, до 900 px видна одна панель, сначала код. Колонки шире 900 px относятся как 2:1, правая не уже 16rem. Таблица одна и прокручивается внутри. Результат проверки — в статусе кода, не отдельным блоком колонки. Каталожный фрагмент `editor-inspector.html` и пример `workspace.html` по-прежнему показывают сети и свёрнутую диагностику образца; рабочие экраны эту секцию не используют. Документ собранного рабочего экрана снаружи не прокручивается. В topbar рабочих страниц нет меню «Ещё» и кнопки «Совместимость»: справка открывается пунктом «Документация» в меню шапки, рядом с «Очистить проект». Номер снимка и отказ заявлять игровую совместимость — в статье руководства.
- В образце поля сети точное совпадение выше остальных, служебный `green_new` виден только по своему префиксу, пункта «Создать имя» нет. Esc, клик снаружи и Tab завершают введённое имя. В поле формы Tab переводит фокус. В тексте редактора Tab вставляет одну табуляцию и пункт не принимает; Enter или клик выбирают подсказку. Форматирование на странице конфигурации: ⌥⌘L на macOS и Ctrl+Alt+L на Windows и Linux, только при фокусе документа. Эти сочетания описаны в руководстве; строка статуса редактора их не повторяет. Плоский вложенный объект без комментария пишется в одну строку. Пустой массив — `[]`, один элемент остаётся в скобках, два и более — каждый с новой строки. У последнего поля и элемента запятой нет. Отмена и повтор на `/` и `pages/configure/` — иконки 32×32 в заголовке рабочей области, меньше кнопок пульта; на грубом указателе 36×40. Подсказка: ⌘Z и ⇧⌘Z на macOS, Ctrl+Z и Ctrl+Y на Windows и Linux; там же повтор доступен через Ctrl+Shift+Z. В поле кода действует история редактора, в остальных полях — локальная отмена браузера. История не сбрасывается при смене панели. Рабочие страницы подключают это поведение отдельно.
- Клик в код не рисует рамку. Фокус с клавиатуры отмечает каркас редактора тонкой линией, каретка и выделение остаются. Единственный источник прокрутки — textarea: колесо, касание и клавиши над номерами строк двигают это поле. Номера повторяют `scrollTop` и не сдвигаются по горизонтали. Подсветка на рабочих страницах сдвигается тем же `scrollTop` и `scrollLeft`. Ширина `.fl-editor__gutter` берётся из текста номеров и не из свободной ширины stage: не уже 2.5ch, не шире 4.5ch, `white-space: pre`, без колонок и переноса. Две цифры занимают меньше места, чем три и четыре; четырёхзначный номер остаётся целиком. `font-size`, `line-height` и верхний padding совпадают у номеров, textarea и слоя подсветки.
- Ошибка, блокирующая запуск, рисуется в слое подсветки красной волнистой линией `var(--fl-red)` под диапазоном текущей ревизии. Образец `code-editor.html` показывает обычный код, неизвестный `SSignal`, синтаксическую ошибку, несколько ошибок и исправленный документ до подключения страницы. Диапазон не заменяет символы и не меняет ширину строки. На `/` и `pages/configure/` тот же набор читается в `.fl-editor__status`: короткая причина, «К месту» для одного диапазона, счётчик и «Список» для нескольких. Длинная строка переносится. Наведение не требуется. После исправления маркер этой ошибки исчезает.
- Нет непрерывной анимации; короткие переходы включаются только при отсутствии `prefers-reduced-motion`.

## Просмотр и проверка через Docker

Из корня репозитория:

```sh
docker build -t f-logic-ui-check:1.56.1 -f ui/tests/Dockerfile ui/tests
docker run --rm -p 127.0.0.1:4173:4173 \
  -v "$PWD:/workspace:ro" \
  f-logic-ui-check:1.56.1 node ui/tests/server.mjs
```

Открыть [каталог локально](http://localhost:4173/factorio-ide/ui/) или [пример страницы](http://localhost:4173/factorio-ide/ui/workspace.html). Сервер нужен только для локального просмотра и отдаёт `ui/`; в GitHub Pages достаточно статических файлов. Все пути относительные, проверка также открывает каталог под `/factorio-ide/ui/`.

```sh
mkdir -p /tmp/f-logic-ui-artifacts
docker run --rm --ipc=host \
  -v "$PWD:/workspace:ro" \
  -v /tmp/f-logic-ui-artifacts:/artifacts \
  f-logic-ui-check:1.56.1
```

Playwright 1.56.1 и axe-core 4.10.3 устанавливаются только в контейнер. Проверка охватывает две страницы, пути из корня и подкаталога, ширины 320–1920 px, отсутствие горизонтального переполнения документа/повторных ID/оборванных ARIA-ссылок, UI-действия, клавиатуру и автоматические правила доступности. Снимки и JSON-отчёты остаются в `/tmp/f-logic-ui-artifacts`. Это не тесты движка и не гарантия полной доступности; ручная визуальная проверка дополняет автоматическую.

Локальный просмотр останавливается командой `docker stop f-logic-ui-preview`, если запущен контейнер с таким именем.


## Документация: готовый библиотечный образец

[Собранная страница](docs.html) · [раздел каталога](index.html#documentation).

- `components/docs-navigation.html` — тематическое дерево, активная статья, мобильный dialog.
- `components/docs-article.html` — два образца статей, связанные темы, нумерованные шаги, копируемый код, примечание, ошибка, ожидаемый результат, предыдущая/следующая статья, неизвестный раздел.
- `components/docs-outline.html` — оглавление активной статьи, раскрытие на узком экране.
- `styles/docs.css` — точная типографика, поверхности, отступы, три/две/одна колонка, active/focus и мобильная панель; использует существующие токены.
- `scripts/docs.js` — `mountDocumentation(root)`: переходы, hash/Back/Forward, оглавление, копирование, dialog/Escape/возврат фокуса. `catalog.js` вызывает после загрузки фрагментов.

При сборке страницы подключить tokens → components → layout → docs.css, разместить три фрагмента в `.fl-docs__layout` и вызвать `mountDocumentation(root)` после вставки HTML. `ui/docs.html` — полный исполняемый пример, а не картинка. При интеграции в публичное руководство использовать эти элементы; каталог и раскрываемые исходники пользователю руководства не показывать. Образец не изменяет редактор, черновик и симуляцию.

## Компактный интерфейс эпика 0004

[Адаптивный образец](compact.html) · [каталог с исходниками](index.html#compact).

- `components/compact-toolbar.html`: play/pause фиксированного размера, шаг/назад/сброс, число скорости и тик. Кнопки демонстрируют состояния без запуска движка. Шапка `compact.html` показывает то же меню, что рабочие страницы: кнопка «Меню» и пункты «Документация» и «Очистить проект». В образце очистка не меняет черновик редактора.
- `components/compact-workbench.html`: шапка с кнопками «Код / Сети / События» и историей стоит внутри панели кода. Переключение меняет область под шапкой. Шире 900 px сети справа; до 900 px одна активная область, шапка остаётся. На `/` и `pages/configure/` те же три кнопки открывают код схемы, одну таблицу сетей и сценарий на текущем URL. Сценарий идёт через Worker и не пишет JavaScript в черновик схемы. Прямая `pages/event/` сохраняет свой заголовок «Код / Сети», код и две раскрываемые секции. Пульт этой страницы оставляет «Проверить» и «Остановить» словами и не добавляет запуск, паузу, скорость и шаг назад.
- `styles/compact.css`: подключать после tokens/components/layout в каталоге и `compact.html`. На рабочих экранах размеры пульта заданы в `layout.css` и совпадают с образцом: кнопки 40×40, скорость шириной 64 px. Остальные правила `compact.css` к страницам приложения не подключены.
- `scripts/compact.js`: `mountCompact(root)` после загрузки фрагментов и `mountWidgets(root)`. Демонстрационные переключения, история, диагностика и прокрутка без исполнения кода. Подключение реальной модели описано в задачах 0003–0008 эпика.
- Общий `data-select` дополнен `data-menu-title` (необязательный заголовок списка), `data-menu-width` (желаемая ширина в px, ограниченная окном), `data-value-only` (в кнопке value вместо подписи опции). `data-label` задаёт доступное имя. `data-search="true"` собирает фильтр, если разметка ещё без кнопки. Заголовок меню стилизуется в `components.css`; пустой заголовок скрыт и не занимает место. Прежние API и события сохраняются; пример с заголовком и без него — `select.html`. Рабочие экраны используют этот же контроль: схема и списки сетей ищут по пунктам, порт с ошибкой подключения получает `aria-invalid`. Компактная скорость подключена к `/`, `pages/configure/`, `pages/debugger/`, `pages/circuit/` и `pages/networks/`: в кнопке число тиков/с, в списке единицы, заголовок меню «Скорость». Панели кода, сетей и событий подключены на `/` и `pages/configure/`; прямая `pages/event/` держит код и сети. На экране событий нет скорости: сессия не задаёт тики в секунду.
