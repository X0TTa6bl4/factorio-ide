Подключение к сети

green_t

Сначала точное имя существующей сети, затем остальные совпадения по префиксу. green_new виден только если сам начинается с введённого текста: при green_t его нет. Пункта «Создать имя» нет. Esc, клик снаружи и Tab завершают введённое имя; в этом поле Tab переводит фокус и не вставляет табуляцию. Для red_new правило то же.

Демонстрация подстановки. Связь с моделью схемы подключается на странице сетей.

Пример ошибки поля: цвет сети не соответствует порту.
