Tab — отступ, Enter — выбрать подсказку. Tab вставляет один символ U+0009 и не принимает пункт, в том числе при открытом меню; визуальный tab-size — 2. Shift+Tab уходит из поля. Форматирование: ⌥⌘L на macOS, Ctrl+Alt+L на Windows и Linux.

Каркас после вставки класса. Вертикальная черта обозначает каретку и не входит в документ. Пустая строка — одна табуляция.

Arithmetic({
	|
})

Один элемент массива остаётся в скобках, плоский объект пишется компактно. Несколько элементов — каждый на своей строке.

signals: [{ signal: Signal.Signals.signal_A, constant: 1 }]
signals: [
	{ signal: Signal.Signals.signal_A, constant: 1 },
	{ signal: Signal.Signals.signal_B, constant: 2 }
]

Ошибка, блокирующая запуск, подчёркивается волнистой линией. Текст сообщения и кнопка «К месту» находятся в панели диагностики и доступны с клавиатуры; наведение не требуется.
