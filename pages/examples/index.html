Запуск по HTTP

Из корня репозитория, если установлен Docker: ./dev/f-logic serve. Редактор открывается как http://127.0.0.1:4173/ и как http://127.0.0.1:4173/factorio-ide/. Конечному пользователю GitHub Pages достаточно браузера.

Пути стилей и модулей относительные. Двойной щелчок по локальному файлу не требуется.
