# Перенумерация задач

`renumber_tasks.py` ставит `signal-constant-catalog` вторым после окружения. Остальные задачи сохраняют относительный порядок. Переименовываются каталоги задач; вложенные файлы перемещаются вместе с ними. Служебные имена `0000-*`, шаги `0100/0200` и глобальный `.task-sequence` не меняются.

Требуется уже установленный Python 3.9+, сторонние зависимости не нужны. Команды из корня проекта:

```bash
python3 tools/tasks/renumber_tasks.py
python3 tools/tasks/renumber_tasks.py --apply
```

Первая команда только показывает план. Вторая обновляет каталоги, ссылки и упоминания четырёхзначных номеров в документации эпика, спецификациях и README. Сырые JSON, Git-история, архивы задач, шаблоны skills и исходный код не изменяются. Повторный запуск после успешного применения ничего не меняет.

При обычной ошибке записи/переименования скрипт пытается восстановить исходные документы и имена каталогов; аварийное завершение процесса или отключение питания не являются атомарной транзакцией файловой системы. Не редактировать те же документы параллельно с `--apply`.

Для проверки на отдельной копии проекта можно передать `--root /путь/к/копии`. Скрипт не вызывает Git и не создаёт коммитов.
